## 实际新增范围

SC-01 增加六个变体，每个三次：三个真实模型语义变体为检查肯定、检查否定、取得目标仍未满足；三个离线变体覆盖必需成员缺失、来源损坏及两种目标不可交叉绑定。旧 V06 的目标、原答、阈值和失败评分保留。

真实语义变体由用户原文启动目标规范化，随后规划、分析与受约束终止；harness 不预选新的 Goal 端口。九个真实槽每槽最大 4 HTTP / 48000 tokens，ORCA 为零，故每轮新增 36 HTTP / 432000 tokens。单 Run 的输入 12000、输出 2000、总 tokens 48000 等上限不变。

离线使用完整 PreparedRequest 上界结算的三个正常流程分别占用 38050、38038、38171 tokens。它们是容量测量，不是真实模型质量或供应商实耗。最多允许一次纠正，须满足当时容量和余额；不保证所有阶段的纠正都能发送，超限必须明确拒绝并确定性交付，不能自动增加预算或启动后续昂贵 Tool。

完整映射为 76 个变体、228 个覆盖槽；共享联合轨迹去重后 225 个核心执行槽。另有六个自主 E2E 和六个独立参考，合计 237 个操作槽。正式轮仍要求同一冻结下完整执行，不拼接前一轮结果。
