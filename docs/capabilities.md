## 执行与读取

| 操作 | 实际状态 | 限制 |
| --- | --- | --- |
| Windows 受管执行 | 原子 Job 绑定、CPU/提交内存、期限、完整树清理已实测 | 仅本地 Windows；其他平台直接拒绝 |
| 环境全局额度 | 同用户执行环境跨 Run / 数据目录共享 1 个槽，未知占用保留 | 不能通过换目录绕过；未知启动不自动重跑 |
| 暂停 / 取消 / 显式恢复 | 本地子进程故障矩阵通过；真实四核 MPI 取消和协调者强杀已验证 | 丢失期间计量无法补齐时保留下界与未知标记；不保证 ORCA 断点续算 |
| 不可变证据与来源 | 原子写、独立尝试、hash、归档/解析一致性已验证 | 外部同权限用户篡改会使旧绑定失效；不伪称文件系统不能被外部修改 |
| evidence.list / text / field | 同一注册表声明与校验；有界、只读、不转换 | 元数据、行号或已知 JSON 字段是观察，不会自动获得科学资格 |
| 报告 | 确定性 JSON：逐输出检查、值、来源、目标与交付状态 | 尚无模型解释或自然语言最终报告 |
