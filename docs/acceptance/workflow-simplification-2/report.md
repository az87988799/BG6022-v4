## 实现范围

依照 [0056](../../decisions/0056-simplify-execution-workflow.md)，新 Run 固定 `workflow_policy=simplified-1`，提示版本 v77。历史 Run 缺少标记时保持原规则及序列化形状。

- 原文引用由程序提供片段和位置；一般分析目标不再误入旧采样路径。明确溶剂由结构化条件识别，保留实际条件。
- 已授权的方法和基组自动选择保留理由，官方资料检索按需。初始几何准备可先于这些选择；条件选择后仅复用经核对的同一身份和几何。
- 模型可引用明确生产步骤及输出口/文件键，程序冻结真实文件 ID、hash、权限和来源。合格几何必须经过对应输出口的检查，不能靠扩展名认定。
- 未覆盖目标自动保留缺口；Python 和原生输入均可简短修复。每次尝试独立，失败目标换 ID 不重置额度。
- 已批准电子态和冻结资源、有限迭代控制在遗漏时写入真实输入，保留原稿和最终输入；明确冲突仍拒绝。
- 当前失败保留短回溯或末尾异常，减少重复读取。空正文且输出截断允许一次有界恢复，继续消耗原预算。
- 独立 Python 工作与同逻辑重试分别计数；确认计算停止后的只读收集使用独立有限期限。未知执行不能作为已停止释放。
- 多来源环境比较按明确来源目标逐一检查，要求完整覆盖候选环境；单环境目标、其他条件和最低证据要求不降低。

未新增任务求解工具、预写科学脚本或生产科学资格。输入准入、真实计算结束、科学证据与用户目标完成仍分别判断。
