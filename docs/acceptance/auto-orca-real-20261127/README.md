# auto-orca 优化前后实测

**新版完整通过 9/9，保持了上轮通过率。开算更早，九次总用时没有下降。** 三道题各自的中位用时都缩短了，但激发态第 1 次作答单独多用 49.87 秒。新版合计 820.74 秒，比上轮技能组多 2.01 秒（0.25%），比上轮无技能组多 205.65 秒（33.4%）。科学评分与 Windows 真实进程核验通过 9/9；新版和旧版技能的 18 份答复混排后，独立盲审逐份核对了结论与原始证据，均通过。三组每题都通过了 3/3。[九轮逐次对比](comparison.csv) · [科学评分、盲审理由和原始证据哈希](comparison.json)

**第一次启动 ORCA 的中位时间从 29.91 s 降到 19.27 s。** 在 9 场中有 8 场提早启动。按调用编号审阅，启动前查看附带源码或 CLI 帮助的工具调用从 13 次降到 2 次；反复检查同一入口的会话由 6 场降到 1 场。两次残留都发生在同一个能量题试次。另有三次 IR 作答在计算结束后各读了一次振动脚本。读取技能正文和题目输入单独记录。首次启动取 Windows 记录的主进程创建时间，旧版起点略早于启动 CLI，新版若用同一口径为 19.28 s。

上轮多出的两个 ORCA 主进程分别来自 `SINGLETS` 解析失败和已完成的 Opt+Freq 为补写 `TightSCF` 重算。新版只启动了题目所需的 6 次单点、3 次 Opt+Freq 和 3 次激发态计算。新版九次都用 `orca_job.py` 启动求解；上轮有两次用该脚本启动求解。两版的三次 IR 都执行了 `bond_modes.py` 做模式归属。

新版两场耗时较长的作答都有**计算成功后的返工**。IR 第 2 次先读错了结果 JSON 中 `normal_termination` 的层级，又把相差一个整体平移的坐标当作几何不同，核对相对几何后完成。激发态第 1 次按字符串比较原坐标和 ORCA 回显，因 `0.0` 和 `0.000000` 拼写不同触发断言，改按数值比较后完成。三次错误都保留在调用记录中。工具执行合计少用 20.89 s，工具以外合计多用 22.90 s；后者包括模型生成、服务等待和编排，日志无法为每一项单独计时。

## 复测条件

2026-11-27，香港时间。沿用 11 月 25 日的三道真实 ORCA 题，每题用新版技能独立作答三次。模型仍为 `gpt-6.2-sol`，推理强度 medium。三个输入题、发给模型的九份完整提示、科学评分器、独立参考输出及 Windows 原生 ORCA 6.1.1 运行环境均已核对哈希。九次按上轮技能组的相对顺序串行，从各自新的工作目录开始。无技能对照沿用上轮的九次实测。[原评测及题面](../auto-orca-real-20261125/README.md) · [本次冻结协议](protocol.json)

原生作业使用 1 核、每进程 MaxCore 192 MB，工具进程树限 1 GiB，模型会话限 720 秒。总用时从 Codex CLI 启动计到退出，包含读技能、模型思考、调用工具、ORCA 计算和交付答案。预检、参考计算、科学评分和答复盲审在此时间之外。单点能量比较须有两次可核实的 ORCA 主程序启动，另两题各须至少一次。求解模型无法读取参考答案和评分器。运行后再次核验了九个独立会话、2,114 个运行时文件和两轮证据的完整性。[运行核验回执](matrix-verification.json)

两轮在同一台机器上分日运行。Windows 桌面应用的安装版本已更新，模型固定的是同一个服务端名称。没有同期重跑无技能或旧技能。每题三次的时间差能描述这些会话，无法独立量化服务延迟或模型波动的贡献。

## 技能改动与定向核验

- 常用作业的完整入口放在 [SKILL.md](../../../skills/auto-orca/SKILL.md) 前部。条件齐全即可在读取几何的同一次工具调用中提交。IR 位移分析命令直接标明原子从 1 起计。
- XYZ 的 `sp`、`opt`、`freq`、`optfreq` 均可用 `--tightscf` 将 `TightSCF` 写入第一次提交的输入。既有作业若按收敛精度验收，可以从输出核对各项实际阈值和收敛事实。[作业入口](../../../skills/auto-orca/scripts/orca_job.py)
- 闭壳层单重态 TD-DFT 入口保存旧输入原件，再将其中的 `singlets true` 转成 ORCA 6.1.1 的默认单重态写法；显式 `triplets false` 仍进入提交文件。用上轮实际报错的原件另做一次真实回放，ORCA 退出码为 0，六个激发根全部算出，原件哈希吻合。[原生回放核验](native-replay.json)

五项定向回归在 Python 3.11 和 3.13 通过，覆盖各类 XYZ 输入、默认条件、原生输入兼容、冲突选项和实际提交回执。技能格式校验通过。[定向回归](../../../tests/skills/test_orca_job_inputs.py)
