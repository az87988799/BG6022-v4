# 甲醛固定几何的六个单重垂直激发

参考计算使用 reference/job.inp；其完整标准输出保存为 reference/job.out。参考值直接读取此独立作业的长度形式电偶极吸收表。初始几何取 inputs/formaldehyde.xyz；参考输入中采用相同的内嵌坐标。固定小数容差在任何参考或试验结果评分前设定。热力学量、波长和速度形式的振子强度不参与打分。

| 检查 | 通过条件 |
| --- | --- |
| reference | 独立原始输出含已收敛 SCF、正常终止、六个单重态及六行完整的电偶极长度表。 |
| provenance | result.json 标出的两个独立工作目录内文件存在，原始 .inp 与 ORCA 回显的输入逐行对应（忽略注释、空白和大小写），原始输出具有 ORCA 版本及正常终止记录。 |
| fixed_conditions | 从输出回显核对 PBE0、def2-SVP、TightSCF、显式 TDA、6 个根、MaxCore 和气相单进程；实际电荷、多重度和按 C/O/H/H 原顺序的坐标与题设吻合，最大逐分量差 ≤ 2×10⁻⁵ Å。单独计算激发态，保持固定坐标。 |
| computed_spectrum | 学生输出有收敛 SCF、六个单重根和电偶极长度表；这些原始值均与独立参考相符。每个根能量的绝对容差为 0.002 eV，长度形式振子强度绝对容差为 0.00005。 |
| reported_values | JSON 的六行根号从 1 到 6，顺序与能量一致；数值有限、非负且同时符合原输出和独立参考，容差同上。 |
| source_lines | 每个根引用自身原始电偶极长度表中的正确行号。 |
| root_assignments | 正确识别最低与最亮根；报告的近暗根在原始输出和独立参考中均满足 f ≤ 10⁻⁵，所交数值也满足此界限。 |
| interpretation | 非空解释，提及激发能、吸收强度或跃迁概率，并明确比较范围为本次算出的有限个根。自动判定仅检查术语和范围，解释的语义由人工复核。 |
