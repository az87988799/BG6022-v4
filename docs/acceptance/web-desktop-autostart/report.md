# Windows 网页登录启动与桌面入口

2026-11-13（Asia/Hong_Kong）。本次范围已实现并部署到当前用户，等待用户验收。

## 交付

依据用户“直接打开网页，不要每次先手动启动”的明确要求及 [0083](../../decisions/0083-windows-web-autostart.md)，新增无窗口启动辅助程序和当前用户快捷方式安装脚本。登录 Startup 快捷方式运行 `pythonw + desktop_web.py --serve`，只启动原有本地网页；桌面“ORCA 分子工作台”运行 `--open`，先复用或有界启动同一服务，再交给默认浏览器打开 `http://127.0.0.1:8765`。

快捷方式已实际安装在当前用户桌面与 Startup 目录，并回读核对项目 pythonw、完整参数、项目工作目录、窗口方式及归属标记。未安装 Windows 系统服务、计划任务、依赖或镜像，未改变公网监听或安全策略。日志位于 `%LOCALAPPDATA%/orca-agent/web/<workspace-hash>/`，不写入科学产物。

健康 GET 固定核对应用、版本、项目/数据根指纹和“不自动恢复 Run”标识；请求禁用代理、重定向，响应不超过 4096 字节。并发桌面打开共用短启动锁，后台服务继续使用原单 worker 和服务锁。未就绪不打开浏览器；错服务不结束、不换端口；启动子进程提前退出时仍在原期限内等待可能已经抢先启动的同一服务，不重新启动第二个子进程。

## 首次失败与修正

第一次探测采用 1 秒超时，本机关闭的 loopback 端口约 2 秒后才返回拒绝连接，因此在未启动子进程时保守失败。探测改为单次最多 3 秒、总就绪期限仍为 20 秒后，实际后台启动通过。

系统 Windows PowerShell 5.1 的 `-File` 执行被其现有脚本策略拒绝，没有执行安装主体。先通过显式 Windows 快捷方式接口完成本机部署，随后使用本机已有 PowerShell 7.6.9 在原 `RemoteSigned` 策略下完整运行安装、卸载及重装脚本成功。未修改执行策略，没有使用 Bypass；5.1 的拒绝不计为安装成功。

## 未验证与限制

已验证实际后台运行和手动触发两个已安装快捷方式；没有实际注销登录或重启 Windows，不把当前会话验证称为登录/重启全链验收。Startup 是当前用户登录后启动，不承诺未登录时服务可用，也不是无限重启的守护服务。桌面入口能在服务停止后启动它。

后台网页部署不等于计算保活：不扫描恢复 Run、不自动调用模型或 ORCA，仍由用户提交或显式继续；原配置、资源隔离、预算、未知执行对账和七题历史验收状态不变。移除启动项不删除配置、数据或已有结果。
