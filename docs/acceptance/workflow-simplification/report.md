# 流程简化与离线修复

日期：2026-10-20。用户授权简化后重新冻结，原七项各进行一次真实 LLM 全流程尝试；本目录只记录冻结前开发和离线验证。决定及契约见 [0055](../../decisions/0055-simplify-workflow-and-refreeze.md)。

## 变更范围

- 请求中已授权且未填写的默认条件由程序补入，并记录来源；真实未知、冲突、方法及基组的选择约束保留。
- 程序生成已知能力与最低证据缺口的说明，允许仅能力覆盖不足的任务继续准备；原目标和最低要求不变。
- 同消息重复引文绑定全部精确位置，共享条件引用由程序保留，身份消费端使用相同位置证据；旧身份记录不升级。
- 过长理由有界收录，原模型响应保留；已知非执行备注保留为备注，未知执行参数仍拒绝。
- 新 Run 将文件写入与 Python 分析额度分开，显式有限计数；旧 Run 保持旧预算与序列化。
- 新结构输入 Step 的体系编号可只填写一次，由程序补齐；冲突和不存在的体系拒绝。SDK 计划可声明明确的同体系上游几何准备依赖，执行时仍检查真实几何。
- 紧上下文只展开当前决策需要的结果，其他历史结果保留数值、检查与来源引用；不删除历史原件，不提高原 12K 测试上限。
- 收尾使用实际构建请求的 token/期限成本和最终解释预留，不将单次输入上限误当本次输入量。实际容量不足时仍有限停止。

不增加专用科学工具或任务解法；未放宽原生 ORCA、隔离、资源、科学检查或用户目标完成标准。提示版本为 `agent-json-v76`。
