## 新暴露或仍存在的问题

1. **T1 的模型输入投影丢失原文。** 路径脱敏从“平移/转动项”的斜杠开始误删后段义务，三份实际模型请求均可复现；原始 Request/用户文本完整。另一次几何标签拒绝使用的是完整原文，其词法判断把警示语当作不确定条件；这与投影丢失是两条不同问题。第三次拒绝涉及初始结构最低证据的未支持项提示。详见 [T1 审查](review/t1-review.json)及[源码诊断](review/t1-source-diagnosis.json)。
2. **T2 仍缺合格初始几何绑定，生成程序也发生错误。** 第一脚本在 RMSD 比较报 `Bad Conformer Id`；第二脚本调用 SDK 时被拒绝，要求当前已准备/注册几何。两次各保存 60 份 XYZ，共 120 个版本化文件；按精确坐标行 hash 去重后为 60 组，第二次重复了同样的 60 组，不称为 120 个不同构象。随后两次模型响应达到单次输出上限，最终有界停止；不是 ORCA 失败或总调用额度用尽。详见 [T2 审查](review/t2-review.json)。
3. **T3/T5 仍未在有限规范化中完成。** T3 后两次涉及初始结构最低证据的提示要求及额外 schema 字段；T5 依次涉及默认 RKS 采用、reason 长度、重复原文短引文定位。完整逐次诊断见 [T3](review/t3-review.json)、[T5](review/t5-review.json)，不把这些统一称为网络错误。
4. **T4 科学原始结果具备，自动解析与交付失败。** 原始输出显示 SCF 8 次迭代收敛、TDDFT 求解收敛、TDA 关闭、五个单重态及长度规范振子强度；初始与计算 XYZ 字节相同。生成脚本期待的表头/行格式与 ORCA 6.1 实际 `Transition` 表不匹配，实际报 `no excitation rows parsed from job.cis or stdout.out`。剩余 1 次模型调用无法同时容纳下一决策和预留的最终解释，因此停止；不是已经调用满 24 次。见[原始响应核查](review/t4-raw-response-check.json)、[T4 审查](review/t4-review.json)。产品科学输出仍为未验证，没有新增 QualifiedOutput。
