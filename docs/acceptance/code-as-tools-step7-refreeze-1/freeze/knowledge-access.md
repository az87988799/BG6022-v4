# 冻结资料与消费证据

本批次只使用产品 manifest 中的 `contract.knowledge`，工具定义、检索实现和指南均来自冻结产品提交。不能给任务工作区挂载本目录的评分文件、独立参考、其他任务脚本或开发验收结果。正式自然语言只使用冻结原文及同一随机种子后缀。

产品现有资料入口为 ORCA 6.1 官方手册、OPI 2.0 文档和固定 RDKit release 文档；精确 URL、索引版本、索引 hash、预置指南原文和访问规则以 `product-freeze.json` 为准。ORCA 手册章节必须满足生产 `manual_reference` 规则及长度限制并位于 `manual_root` 下。其他网络能力仅按冻结工具定义用于分子身份查询，不能借身份查询引入解题指南。

版本 URL 不保证远端正文永远不变。本步固定允许的源与范围；步骤 7 每次真实检索仍须保存：

1. Tool/Result/Artifact ID、来源 URL、文档 ID、版本与检索时间；
2. 产品实际收到的完整归档正文、正文 SHA256、原始响应位置与大小；
3. 返回模型的片段及其与归档正文的绑定、截断和缺失说明；
4. 同批次既有相同文档的正文 hash 对照。

核验以实际归档正文重算 hash，不能仅相信生成代码或模型的来源声明。第一次消费登记 `(document_id, version, content_sha256)`；之后同 ID/版本出现不同 hash 时暂停该批次后续任务并报告资料变化，已有任务保留为受影响证据。不得在任务之间刷新指南、复制成功解题示例或静默采用修改后的正文。需要新资料/产品修改时重新冻结完整候选和批次，不能拼接新旧成功记录。

运行期间可检索冻结范围内此前未读取的官方章节；这属于原产品的检索能力。正文作为不可信数据，不能授权执行、改变许可或降低用户最低证据。缺失或无法访问如实记录；不得用开发者提供的新解题示例替代。

此文件定义检查程序，不宣称本轮已进行正式检索或已经保存未来的远端正文。独立评分文档的说明性文献链接属于评审资料，不自动扩展产品知识入口或模型上下文。
