# Code as Tools 步骤 6：预定评分与独立参考规则

日期：2026-10-20（Asia/Hong_Kong）。本文件与 [public-tasks.json](public-tasks.json)共同定义待冻结的公开任务和评分规则，服从[现行专项方案](../../CODE-AS-TOOLS-IMPLEMENTATION-PLAN.md)。**规则文件存在不表示已冻结成功、取得参考结果、执行正式任务或通过步骤 7。** 实际冻结 manifest、有效配置、参考程序版本和整批账本须另有可核验记录。

## 1. 固定对象与评分结论

T1—T5 每项恰有三个正式重复槽，共十五槽；H1/H2 在产品冻结后由用户或未参与开发的独立评审另选，每项三个槽，实际选择由 `holdout-selection.json` 提供。本文件不预选 H1/H2，不把已经开发的另一个分子名称当保留任务。参考答案、独立核验程序和前次成功脚本均不得进入产品上下文或任务挂载目录。

实际输入按 JSON 的 `original_text`、`seed_policy.separator` 和预定种子后缀组成。分隔符解码后是两个实际 LF（U+000A，字节 `0A 0A`），不是反斜线和字母 n，也不是 CRLF；每次记录精确 UTF-8 字节及 SHA256。重复 1/2/3 的算法种子分别为 1701/1702/1703；不同任务使用相同种子表，不能失败后改种子重选成功。模型提供商若无固定随机种子接口，则如实记为不可固定。新工作区只含本次授权输入，不继承前次结果、缓存脚本或参考输出。

每次同时报告五个独立结论：执行状态、产品科学检查覆盖、独立评分、目标满足、报告完成。独立评分取 `pass`、`fail` 或 `unverified`，并给出每一必需项的证据路径/hash、原始位置、实测值、容差和理由。缺参考、费用/用量未知、环境缺失、缺必需产物或评审未完成均不能自动变成通过。`unverified` 不满足整批通过条件。独立评分通过不写入 `QualifiedOutput`，不回填产品历史检查。

三个正式槽必须各自通过才可报告该任务通过。首次失败、自主修复和最终结果都保留在同一槽；不能删除失败、增加成功槽来凑三次，不能换 ID 清预算。产品或提示资料变化后需要新候选和新批次，旧失败保留。开发者替产品填写 Plan、任务输入或求解/来源修复脚本的槽不能记为自主通过。

## 2. 独立性、方法选择与参考生成时机

独立评审可以人工逐行核验，不要求为每种性质新增生产解析器。使用的短核对程序必须仅在评审工作区运行，保留其源码、版本、输入清单与输出；不可导入或运行产品生成的解析器作为唯一判据。先独立读取原始 ORCA 输出和结构，再对照产品表格，不能把产品数值复制成参考答案。

方法自动选择遵循固定程序：

1. 第一次科学执行前，从产品已批准的 Request/Plan、选择理由、资料 Result 和拟执行输入登记方法、基组、电荷、多重度、电子态、环境、几何来源、RI/色散/网格/SCF 等实际科学设置。允许产品预算内自主修复，但每次改变均记录；用户固定条件不得改变。
2. 独立评审不依据结果好坏改变可接受方法。依据已冻结官方资料确认所选方法能计算所要求的物理量，基组覆盖元素，响应/频率类型与实际程序相容；无法判定记为未验证。运行成功不证明方法适合所有物理问题。
3. 产品输出归档后，评审按本文件已经固定的输入生成规则，从原始实际输入及几何产生参考输入。只能作明确列出的转换（例如去除优化并在最终几何重做单点），逐行记录差异及原因。不能改变科学模型来追上产品答案。
4. 参考启动前冻结原输入/几何/hash、生成后的参考输入/hash、ORCA/依赖/镜像版本、资源、启动及工作量预约、核对程序版本；之后才执行参考。参考结果不返给仍在运行的产品。此顺序允许自动选择方法，同时避免看结果后更换阈值或参考算法。
5. 原产品的首次失败、修复输入及最终输入分别保留；参考针对最终声明成功的输出核验。失败修复能力还须由控制矩阵覆盖，不能只挑成功 Attempt 隐藏先前失败。

参考使用与正式候选相同的固定 ORCA 可执行文件/镜像、依赖和科学设置，并使用独立干净工作区。相同程序的独立重算验证重现性；它不构成另一量子化学程序的交叉验证或实验准确度验证。任何新数值都必须有单独参考执行回执，禁止无记录的宿主 shell 求解或自动下载依赖。

每个任务/重复一个参考预约槽，通用上界为 30 次 ORCA、30,000 工作单位、21,600 秒、0 模型调用；这包括参考失败、重复尝试和未知占用。公开任务进一步限制：名义成功路径参考数为 T1=1、T2=4、T3≤9、T4=1、T5=2，每项必需参考最多一次已确认失败后的同输入重试，因此各题每槽硬上限分别为 2、8、18、2、4，公开十五槽合计名义≤51 次、含参考重试≤102 次。状态未知先对账，不能把同输入重试当成盲目重启许可。H1/H2 的参考规模另由冻结后的独立评审规定，仍不超过每槽30次。参考预算上限不是允许降低目标的理由；不足时保留未验证。数值频率的内部位移和松弛扫描的迭代要按实际准入规则计工作量，不能用“一个输入文件”视为一次单点成本。

## 3. 共有证据和容差

必查项包括：冻结身份一致、实际真实模型/ORCA回执、全部 Attempt 和内部调用、初始几何不变、完整代码/输入/原始输出及 hash、正常终止与相关收敛、字段单位和条件、报告对不确定性的陈述、累计预算不重置。模型或脚本的 `passed` 不能代替这些检查。

数值阈值见 JSON 的 `common_tolerances`，是本轮预选工程阈值，**不是官方科学准确度承诺**。与原始打印值的抄录/算术核对较严；独立重新计算允许较大的数值差异；不能用后者容忍报告抄错。若差异越界，先报告失败/未验证；不得事后扩大容差。核对程序或评审错误可公开纠正，但保留原判断、纠正证据和版本，不改科学结果。

| 性质 | 对产品原始文件的核对 | 同设置独立参考 |
| --- | --- | --- |
| 电子能量 | 绝对差≤1×10⁻⁸ Eh | 相同几何≤1×10⁻⁶ Eh |
| 相对电子能量 | 算术差≤0.001 kJ/mol | 差值差≤0.01 kJ/mol |
| 坐标 | 同序分量差≤1×10⁻⁶ Å；比较输入优先核对相同几何文件hash | 不比较不同独立优化路径的最终构象作为唯一答案 |
| 振动频率 | 按模式编号≤0.01 cm⁻¹ | 同几何/质量/缩放的逐项差≤2.0 cm⁻¹ |
| 激发能 | 按原态编号≤0.0001 eV | ≤0.001 eV |
| 无量纲振子强度 | 同一规范≤1×10⁻⁶ | ≤1×10⁻⁴，近简并按下述规则 |
| 约束二面角 | 周期角差≤0.5° | 从最终坐标独立计算 |

打印或明确舍入的报告值按 JSON 的最后打印位规则处理；不允许改来源、态号或符号。表格必须保留足够机器精度。换算常数固定为 2625.4996394799 kJ·mol⁻¹/Eh；不同有出处的常数先核对各自算术，不能混用。ORCA 的原始单位及转换约定另见[官方单位说明](https://www.faccts.de/docs/orca/6.1/manual/contents/orcaarchitecture/conversionfactors.html)，本常数不冒称逐字取自该页。

## 4. 逐题评分

### T1

独立确认乙醇连通关系、C2H6O、9 原子、中性单重态和气相。优化必须有相应收敛标志及最终收敛表；核对频率计算采用同一收敛几何。仅输出末尾存在能量或正常终止不够。ORCA 对几何优化提供明确收敛阈值，应按实际输入对应级别核查，不以单一能量阈值代替全部收敛要求。[官方优化说明](https://www.faccts.de/docs/orca/6.1/manual/contents/structurereactivity/optimizations.html)

核对 27 个模式、21 个非平移转动振动及六个平移/转动模式的处理；全部模式包括零值和负值均保留。平移/转动投影产生的零值本身不能证明 Hessian 的质量；显著负频率与极小值结论冲突。[官方频率说明](https://www.faccts.de/docs/orca/6.1/manual/contents/structurereactivity/frequencies.html)

本题要求收敛优化与完整频率分析，不额外把“必然无虚频”暗加为完成条件。负频率必须原样交付并说明不能据此确认极小值；仅诚实披露局限并不补足缺失的频率或未收敛优化。独立参考不完成、27 项缺失、错误几何、虚构单位、将有虚频称作已确认极小值均不能通过。对于接近零的非平移转动模式，不能擅自截成零或用统一容差宣称无虚频；记录为极小值确认未决，参考与分析仍按实际值评分。

参考以最终几何单独重做同类型频率；独立读取 stdout 与 `.hess` 的相关部分。频率排序/编号和缩放、质量、投影设置一致才比较。若产品选择数值频率，仍适用原容差与预算；超限不转为较低要求。

### T2

至少保存八份实际候选；不把“请求生成数量”当作实际产生数量。至少四个成功单点排名成员须保持同一方法、基组、电荷、多重度、环境及能量定义。保存所有实际生成成员、选择/排除、失败和未计算状态；力场优化未收敛必须标注，不将力场预筛选能量冒充 ORCA 能量。

独立去重在几何副本上进行。核对正己烷六个相连碳及各碳氢数；对六个重原子列出碳链正向/反向两个化学等价映射，分别作允许旋转和平移、禁止镜像反射的最小 RMSD，取较小值。以≤0.15 Å判为重复；至少四个排名成员两两>0.15 Å。原候选不可因对齐而改写。RDKit 的对称性对齐接口可用于独立核对，但其部分接口会移动传入分子，所以必须使用副本；冻结实际安装版本，不能把在线最新版当作已安装版本。[RDKit 官方接口](https://www.rdkit.org/docs/source/rdkit.Chem.rdMolAlign.html)

全部排序值从原始 stdout 独立提取并复算。差≤0.01 kJ/mol的项归为并列组，组内按候选 ID 稳定显示，不据此强称唯一物理最低者。参考重算原始能量最低的四个不同成员。若产品额外计算其他成员，所有项仍核对原始文件，参考四项的选择规则不能人为挑较易通过者。

结论限于本次成功评价的有限集合。未做 ORCA 优化/频率时，不能称为经 ORCA 验证的局部极小构象或自由能排序；本题并不要求这些额外计算。算法、种子和去重/预筛选事实须可追溯，禁止运行后修改候选清单掩盖失败。

### T3

七个粗点全部必需，-180°与180°作为两个端点分别保留来源和收敛事实，但不把它们当不同物理角度。ORCA 松弛扫描是在固定所选坐标时优化其他自由度，不能用无约束优化后任意给点贴角度标签。[官方扫描说明](https://www.faccts.de/docs/orca/6.1/manual/contents/structurereactivity/optimizations_scans.html)

在查看粗扫能量前，独立评审保存产品事先声明的判据原文/hash，并按以下固定清单审核：有明确数值量、单位和阈值；能由粗点数据复算；针对曲线分辨率、低能区不确定性或局部变化；在有限输入范围内既可能满足也可能不满足；没有把“预算允许”或“固定跑两个点”当唯一判据。缺任一项，该反馈能力评分不通过。评审不能替产品补写判据，也不能在见到结果后修改阈值。这是与自动方法选择同类的预先登记程序，不要求评审提前提供求解算法。

粗扫结果必须返回同一 Agent 主循环。独立评审按原判据复算触发状态，核对新增/停止决策和实际执行一致；新增点须针对判据指出的区域，最多两个且不是已有周期等价点。达到阈值且预算充足却不执行其宣称必要的加密，或阈值未触发却无理由盲目追加，都不通过该项。若预算不足，只能部分完成，不能事后改判“不需要加密”。若原判据明确得出无需加密，七点完成并正确停止可以通过本题；强制配对控制另覆盖两种动作。

每点独立计算中心二面角并核对≤0.5°；独立读优化收敛和最终几何，按最终几何重做参考单点。原生单次扫描可包含七个内部点，其实际迭代/工作量须完整核算。曲线必须有度、kJ/mol、数据点与插值区别，CSV和图一致；失败点不得接成已计算的平滑成功曲线。端点差异超过相对能量容差须说明可能扫描方向/不同其他自由度，不能悄悄平均或抹掉；这不替代七点各自有效性核对。

### T4

核对丙酮 C3H6O 的10原子身份、同一次计算几何、中性单重态和五个单重垂直响应根。TDDFT/TDA选择须显式记录且输入、输出、报告一致。ORCA 的响应根数由相应响应设置决定，原始响应计算与吸收输出需关联。[官方响应说明](https://www.faccts.de/docs/orca/6.1/manual/contents/spectroscopyproperties/tddft.html)

逐态读取真实激发能和电偶极**长度规范**振子强度；检查表头，不能把速度规范、跃迁偶极分量或轨道能差列混进来。ORCA 6.1 的吸收输出明确区分能量、波长和振子强度。[官方单光子谱说明](https://www.faccts.de/docs/orca/6.1/manual/contents/spectroscopyproperties/ops.html)

同设置参考采用原始几何重做五态响应。按激发能升序，将相邻能量差≤0.001 eV的根作传递闭包分组；产品和参考分别分组，必须能按能量区间一一对应，根数一致。非简并根逐态比较；简并组比较排序能量集合及组总振子强度，组强度容差为组大小×1×10⁻⁴，避免将数值旋转导致的组内强度重分配误认作抄录错误。产品对自身原输出仍须逐态正确，不得利用分组省略态编号、零/弱强度或失败根。

几何可以是本次已说明来源的初始几何，不强制另做优化；若报告声称为优化几何则必须有收敛证据。正确报告方法近似与结构限制，不宣称实验峰、绝热能或普适定量精度。产品和参考的五态不能按上述规则匹配时记未验证，不擅自降低为四态，也不事后要求本题没有指定的额外根。

### T5

两个作业采用同一乙醇有序几何和同一方法/基组/态/SCF/网格；只允许气相与 C-PCM 水所必需差异。优先同一XYZ Artifact/hash；若仅注释/格式不同，逐元素逐坐标精确核对输入数值且记各自hash，不因大致重原子RMSD接近就当相同几何。

从原始输入和输出确认溶剂模型、水和实际可见介电/空腔设置，气相不能隐式沿用溶剂选项。C-PCM 是连续介质近似，其计算量与完整实验水合自由能不能混为一谈。[官方隐式溶剂说明](https://www.faccts.de/docs/orca/6.1/manual/contents/essentialelements/solvationmodels.html)

独立参考两个同设置单点，计算 `ΔE=(E_water−E_gas)×2625.4996394799`，保留符号。不能事先假定差值必负；实际数值和符号由原始证据决定。禁止分别优化几何、使用不同基组或将模型的电子/极化贡献差命名为完整水合自由能。缺少热力学/标准态证据不能补猜。
