## a027 实际科学与修复事实

固定初始乙醇 XYZ（859 字节，SHA-256 `5341a7b8b4268ed330dc280e58a3dcf05b1fd766ee331dc1de2eff7cac9d4257`）用于两个 B3LYP/def2-SVP、RKS、0/1 计算，环境分别为气相与 CPCM 水，其他条件相同。独立原件核对得到气相 `-154.817054999208 Eh`、水环境 `-154.823380641772 Eh`，水减气为 `-16.6079722712607102624636 kJ/mol`。这是该指定计算条件的电子能差，不是水合自由能，也不是独立参考精度认证。

两个内部 ORCA 均真实完成。原父 Python 在计算后因 `null` NameError 失败；两次修复仅将它改为 `None`，相同 SDK key 与输入指纹复用原完成回执。随后两个 Python 和差值分析均 completed，实际 ORCA 始终为 2。原失败父尝试继续保留，不把复用误计为新计算。

[原件核验 v3](attempts/a027/independent-raw-check-v3.json)的 8 项自动检查通过；[手工核验](attempts/a027/manual-review-a027.json)为 5 项通过、1 项失败，缺负号含义解释。旧 v2 核验中 CRLF 文本视图造成的保守未验证记录保留，v3 只改审计的标准换行视图，736 份读取源 hash 未变。最终 Plan 的差值和交付仍为 gap，原状态 failed/partial。不使用开发者补写说明冒充模型完整交付。
