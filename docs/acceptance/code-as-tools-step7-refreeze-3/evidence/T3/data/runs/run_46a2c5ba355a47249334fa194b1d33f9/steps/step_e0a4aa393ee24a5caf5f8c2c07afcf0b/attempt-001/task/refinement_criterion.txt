Predeclared refinement rule: after the seven coarse constrained optimizations, sort points by actual dihedral. Refine only if (i) adjacent relative energies show a slope sign change bracketing an interior extremum, or (ii) an adjacent pair differs by >2.0 kJ/mol while the lower-energy point is not at a requested angle and a midpoint could lower the energy by >0.5 kJ/mol; add at most two midpoints. Do not refine if the coarse curve is monotonic, all adjacent differences <0.5 kJ/mol, or convergence failures prevent reliable comparison. This is a numerical sampling criterion, not transition-state validation.
