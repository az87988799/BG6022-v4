# B-04 / B-05：模型传输与单一反馈循环

已实现受控 DeepSeek JSON 提案、发送前持久预约、专用费用结算、有界上下文和唯一反馈循环。结构化入口以确定性策略复用该循环，保持零模型调用。SDK 固定 `openai==2.28.0` / `httpx==0.28.1`；实际 SDK 的离线 MockTransport 测试验证了请求体、无隐式重试、拒绝重定向、响应大小限制及异常脱敏。

本机安装包许可证已核对：openai 2.28.0 为 Apache-2.0，httpx 0.28.1 为 BSD-3-Clause；许可证随锁定发行包保留，ORCA/OPI 的既有版本与许可证记录继续适用。

模型只从进程环境 `DEEPSEEK_API_KEY` 读取密钥，认证信息不进入请求存档、模型上下文或 ORCA 子进程环境。未知 HTTP 用量保留预约，恢复缺失响应不会盲目发送。普通 Run 保存不能退还未知用量或改写已记录的模型调用。费用按实际已知 tokens 乘以冻结最高未缓存价估算上界，未查询账户实扣金额。

`ask REQUEST_BUNDLE.json` 接收自然语言原文与独立目标、条件、文件授权；bundle 不接受 Plan/Step。`message RUN_ID TEXT` 可在模型等待时通过短控制锁保存消息；明确的用户字段补充可用 `--update-file`，会使当前计划失效。模型不能自行改 Request、许可或预算。`report RUN_ID` 不调用模型或启动计算，报告已有事实和缺口。
