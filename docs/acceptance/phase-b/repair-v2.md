## 原始文字入口

`orca-agent ask request.json` 继续使用同一个前台 Agent。省略 `goals` 即进入原始文字规范化；文件只需要原文、已授权文件引用、程序许可及预算。仍支持原来的规范 bundle 和无模型的 `run` 入口。

```json
{
  "text": "优化登记的水，输出优化后的电子能，气相 RHF/STO-3G，中性单重态。",
  "geometries": [{"id": "water", "file": "water.xyz"}],
  "allowed_tools": ["orca.sp", "orca.opt"],
  "scientific_execution": false
}
```

此示例允许模型识别需求但不许可科学执行；识别会计入模型预算。若条件缺失，保持未决。可选 `semantic_defaults` 是用户配置的逐字段默认，规则为 `local-hf-1`，不能覆盖明确未知或已给条件。初始澄清不要求 ORCA 安装，真正科学执行前才检查环境。

`message <run_id> "..."` 只提交消息，前台协调者存在时由它处理，否则显式 `resume`。`--update-file` 是用户编写的规范修订，仍只入队；模型候选没有该权限。`status` 和精确状态短句返回已有快照，不启动 Tool 或模型。继续、暂停、恢复和改题都不退款、不延长 deadline。
