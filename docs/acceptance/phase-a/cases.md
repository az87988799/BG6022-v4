# 阶段 A 首批科学用例与独立核验方案

版本：3；首次冻结日期：2026-10-06（Asia/Hong_Kong）。**各用例输入均在该用例真实运行之前冻结；水 Opt v2 补充严格收敛算法控制，文档 v3 补充已开放的甲烷 Opt 组合。** 清单中的科学状态是冻结时快照；后续运行的证据与验收结论单独记录，不回填为预设答案。

用例数据位于 [`tests/fixtures/phase_a`](../../../tests/fixtures/phase_a)。其中 `cases.json` 是验收数据清单，不是运行时 Request/Plan schema；`reference.inp` 是独立于产品 OPI 生成器、在相应用例运行前手写的输入核对稿，产品不得因此开放任意 ORCA 文本透传。首批输入早于适配器实现，甲烷 Opt 是收尾能力组合审计时补充的用例，不宣称其输入早于适配器实现。

## 冻结范围

只考虑 H₂O、CH₄，中性单重态、闭壳层 RHF/STO-3G、气相、非相对论、无色散、无约束；输入单位 Å，目标能量为含核排斥的总 SCF 电子结构能量，单位 Eh。选择 HF 的工程理由是小体系成本低且无需引入 DFT 网格或辅助基组的额外误差来源。STO-3G 是 ORCA 内置最小基组，覆盖本次 H/C/O。[ORCA 基组表](https://www.faccts.de/docs/orca/6.1/manual/contents/essentialelements/basisset.html)

本轮用例检验计算底座，不声称 DFT、化学精度或更广方法组合已可用。坐标由项目固定为测试输入，未宣称实验几何；优化初始水结构刻意拉长且不对称。原子顺序是结构身份的一部分，每次独立尝试复制为 `geometry.xyz`，ORCA basename 使用 `job`，防止优化输出覆盖初始结构。

通用条件：`RHF STO-3G TightSCF NORI NoAutoStart`；`%scf MaxIter 100 ConvForced 1 end`；4 个进程；每进程 MaxCore 192 MB；系统层总内存 1024 MB；全环境最多 1 个任务；SP 限时 120 秒、Opt 限时 300 秒；每个逻辑步骤最多 1 次尝试，不自动修复。参考核验另计一次显式预算，失败后不无条件重试。时间上限是本项目预先选定的验收预算，不是官方运行时保证。

收尾审计发现首批 `cases.json` 声明的单次预算与最初生产 `request.json` 模板不一致：早期单步骤生产 Run 的持久化上限是每步 3 次尝试、总共 4 次 ORCA 启动，实际各只启动 1 次；`water_opt_sp` 链实际启动 2 次。它们没有在失败后扩大额度，仍处于用户方案默认的 3/4 上限内。现已仅将后续复现用的五个单步骤模板收紧为每步 1 次、总 1 次、额外 0 次，链模板为每步 1 次、总 2 次、额外 0 次；新甲烷 Opt 从开始即为 1/1/0。历史 Run、许可、预算和成本保持原样，不追溯声称历史上限是 1。此次只改模板预算，不改科学输入或检查判据，不据此重算已有用例；预算边界由离线回归覆盖。

水 Opt v2 额外固定 `%geom EnforceStrictConvergence true end`，要求优化器继续满足已冻结的全部五项判据。v1 在首个真实 Opt 中触发 ORCA 的“步长超额收敛、梯度合理”替代停止条件，未达到本项目的全部阈值，结构端口被正确拒绝。v1 输入保留为两个水 Opt 用例目录的 `reference.v1.inp`，历史结果与成本不改写；v2 不改变方法、电子态、初始坐标、科学门槛或运行上限。甲烷 Opt 首版即采用该严格控制。官方在 GOAT 章节说明该优化器开关可令不同分子使用一致判据；本项目只采用 `%geom` 控制，不启用 GOAT。[ORCA 严格收敛控制说明](https://www.faccts.de/docs/orca/6.1/manual/contents/structurereactivity/goat.html)

## 用例清单

| 用例目录 | 冻结输入 | 预期证据与输出边界 |
| --- | --- | --- |
| `water_sp` | 3 原子 H₂O，固定坐标，SP，SCF 100 次上限 | SCF 收敛、有限总能量、正确方法/电子态/单位/几何及来源；通过独立核验后才发布能量 |
| `methane_sp` | 5 原子四面体 CH₄，SP，SCF 100 次上限 | 与水相同的检查，证明解析和检查未硬编码单个分子 |
| `water_opt` | 畸变 H₂O，`TightOpt`，优化 100 次上限 | 按指定优化判据收敛；逐项验证最终能量和对应结构；初始 geometry hash 不变 |
| `methane_opt` | 与 `methane_sp` 字节一致的四面体 CH₄ 坐标，`TightOpt`，严格五项，优化 100 次上限 | 补足当前已开放 CH₄ × Opt 组合的直接证据；逐项检查能量、结构、初始几何完整性，再对独立参考复算 |
| `water_scf_limit` | 同 `water_sp`，只有 SCF 上限降至 1 | 候选 SCF 不收敛反例；须从真实输出确认发生 SCF 耗尽，禁止发布合格能量；保留原始观察 |
| `water_opt_limit` | 同 `water_opt`，只有优化上限降至 1 | 候选优化耗尽反例；禁止发布“已收敛优化结构”；有收敛 SCF 的局部能量须绑定具体迭代与结构，另行检查 |

`MaxIter=1` 不能先验保证某个 ORCA 版本一定呈现所需失败。若实际意外收敛、输入被拒绝、先遭内存限制或运行超时，就记录该事实，用例不算目标失败通过；保留全部尝试，提交新的输入修订并说明原因后再验收。真实失败 fixture 只能来自真实运行及可追溯原始产物。

甲烷 Opt 在运行前固定为 RHF/STO-3G 中性单重态，SCF/Opt 各 100 次上限，4 进程、MaxCore 192 MB、总内存 1024 MB、单次 300 秒；生产与独立参考各允许 1 次启动、无额外启动预算。参考输入单独手写，保持 `NORI`、`NoAutoStart` 与严格五项；能量差上限 `1e-7 Eh`、保持原子顺序的距离矩阵差上限 `1e-5 Å`。增加此用例只补证据，不扩展生产工具、参数或分子支持范围，冻结时参考值仍为空且真实科学状态未验证。

SCF 收敛要求来自真实收敛证据，不能只看退出码、正常终止文字或任意最后一个能量值。`TightSCF` 的能量变化门槛为 `1e-8 Eh`，还有密度、误差及默认收敛模式；`ConvForced=1` 用于阻止未收敛波函数被继续使用。[ORCA SCF 规则](https://www.faccts.de/docs/orca/6.1/manual/contents/essentialelements/scf.html)

`TightOpt` 对应能量变化 `1e-6 Eh`、最大梯度 `1e-4 Eh/bohr`、RMS 梯度 `3e-5 Eh/bohr`、最大位移 `1e-3 bohr`、RMS 位移 `6e-4 bohr`。实际判定还须核对 ORCA 最终收敛表及正常完成的优化阶段；不能仅以单个阈值或最后一帧代替收敛。当前不计算 Hessian，因此合格表述限于“按指定判据收敛的结构”，不宣称无虚频极小值或全局最低能量。[ORCA 优化判据](https://www.faccts.de/docs/orca/6.1/manual/contents/structurereactivity/optimizations.html)

## 独立核验与容差（先于实现冻结）

选择“独立编写标准输入及另行核对原始输出”的路线。初次冻结时没有参考能量或优化坐标，因此清单的参考值为 `null`，参考状态为 `not_verified`；程序必须把缺少参考视为尚未完成该项验收，而不是跳过比较后宣称通过。标准输入由开发助手依据手册预先编写；这属于开发审阅，不宣称已有真人化学专家签字。

1. 在 A-05 管理条件通过后，由独立审阅者核对本次已冻结的坐标、单位、电子数（H₂O 与 CH₄ 均 10 个电子）、RHF、基组、SCF/优化阈值和资源输入。审阅者不能用被测适配器生成的结果修改本用例的标准答案。
2. 使用锁定的同一 ORCA 版本，在独立尝试目录执行预先编写并经开发审阅的 `reference.inp`；依旧经已登记的受管执行边界、许可和预算。参考输入不得使用待测 OPI 输入生成器，数值对照不得使用待测结果解析器；正常产品收集链仍保存其自己的检查，独立对照另读原始文件。保存独立原始输入/输出、版本、hash、成本、审阅方式和结论；没有此记录就没有独立数值验收。
3. 从原始输出独立核验 SCF 是否收敛、总能量的物理含义及单位、原子顺序、电子态和方法。把原文定位及独立核验值保存为单独参考证据，再与被测 Result 对比。直接把 Result 序列化成 expected 文件不构成独立参考。
4. Opt 先独立核查最后优化收敛表、最终结构与最终能量属于同一阶段，再与独立标准输入运行比较。静态 `Opt → SP` 后续用例须绑定该生产尝试的已合格结构；优化未通过时消费者必须停止。

| 对比对象 | 冻结容差 | 依据及失败处理 |
| --- | --- | --- |
| 解析值对同一原始输出字段 | 不超过原始字段末位舍入误差（末位量级的一半，外加浮点表示误差） | 这是读取正确性检查，不能使用较宽的科学容差掩盖取错字段或单位 |
| SP 对独立标准输入运行的总 SCF 能量 | 绝对差 `<= 1e-7 Eh` | 同版本、方法、几何与电子态；预留约 10 倍 TightSCF 能量收敛门槛，作为工程重复性门槛，不等同于理论误差估计；超差先调查，不从实测差值放宽标准 |
| Opt 对独立标准输入运行的最终能量 | 绝对差 `<= 1e-6 Eh` | 仅在双方均满足相同 TightOpt、最终几何匹配且 SCF 收敛时比较；与 TightOpt 能量变化门槛同量级 |
| Opt 最终结构对独立参考结构 | 保持原子顺序的全部原子间距离差 `<= 1e-3 Å` | 避免平移/旋转造成坐标假差异；量级参考 TightOpt 位移门槛，但属于项目预先选择的重复性标准，不能替代梯度收敛证据 |
| 初始几何、归档原始文件 | SHA-256 严格相同 | 不使用浮点容差代替文件完整性；外部只读引用每次消费前重核 hash |

这条路线独立于本项目输入/解析代码，核验计算链与报告可信度；它不是两个量化学引擎的交叉验证，也不能证明 HF/STO-3G 对实验的精度。若将来需要跨引擎核验，须事先统一基函数、哈密顿量和收敛条件，单独记录参考版本及容差。

实际独立复算入口为 `tests/live/test_reference.py`，默认离线时跳过，只有显式 `--live-orca` 才运行。它仅在测试范围替换输入构造为冻结文件复制；其余 Request/Plan、许可、预算、环境全局额度、受管后端、结果存档全部复用生产链。对照能量由另一段原始 stdout 正则读取；结构由独立 XYZ 距离计算读取，不把被测 Result 当参考答案。本次复算对照额外采用更严格的统一能量差 `1e-7 Eh`、Opt 距离矩阵差 `1e-5 Å`，均在独立复算前确定，没有放宽上表标准。收据写入 `data/acceptance/reference-<case>.json`，包括前后文件 hash、两侧原始值及行号、全部实际预算和后端资源回执。再次调用已完成参考时只核验原有证据，失败参考也不得自动重算。
