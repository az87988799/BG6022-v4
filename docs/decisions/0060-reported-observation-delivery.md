# 通用观察的交付与科学验证分开

日期：2026-10-21。依据用户持续真测、删除冲突旧规则并跑通原问题的明确授权。

## 根因

真实 T2 a005 已保存 64 个候选并完成四个统一条件的 ORCA 单点；归档、数值与去重经独立读取核对。六条已接纳观察仍全部不能完成交付：原文最低证据不属于历史三个检查词，便一律被判不支持；程序、筛选和种子报告又被要求提供全局量子化学条件的原生证明。这使合法的新任务和 `reported_with_limitations` 契约不能完成。

删掉用户要求或把未知检查记通过会降低目标；按每题补专用求解器/性质枚举与 Code as Tools 相冲突。本次采用明确版本的有限报告交付语义，保留两类事实。

## 新 Run 的显式策略

1. 冻结 `observation_delivery_policy=reported-observation-1`。历史缺字段使用原严格行为，序列化不补字段；旧 Result、检查、最低证据及 Run 状态不升级。
2. 仅适用于 `generic-observation-1` 且用户未要求专门资格的 `reported_with_limitations` 目标。没有注册 evaluator 的原文义务完整保留为 **unverified**，包括来源、实际数据与检查缺口；不记为 passed、qualified 或已经证实满足。报告交付可以完成，科学资格与未验证义务必须独立展示。
3. 已有注册检查、明确资格要求、失败的一致性检查、真实缺失、来源/hash/系统错误及条件矛盾继续阻断。不存在科学来源时，不得用任务 JSON、文件名或自报执行标志替代原文明示的真实 ORCA 计算。原生来源仍逐一核对完整实际条件，不由另一正确来源弥补错误来源。
4. 纯任务程序、生成物、分析和元数据按同 Run/Attempt、批准的系统、代码、真实文件与 hash 验证交付来源；不能自动借用 Request 的量子条件，也不因未引用原生输出而被要求额外计算。明确 Goal 物理条件、几何约束或原文明示的原生计算要求仍适用。
5. 终端快照、必需事实与实际报告必须包含未验证原文义务及科学资格限制，不能把“交付完成”写成“所有最低科学要求验证通过”。计数、阈值、单位和几何义务不从 Goal 删除；本轮不暗加按题的自然语言科学判定器。
6. 新模式的 Goal 完成基准显式记为 `reported_delivery`。存在必需目标的未验证原文义务时，顶层 `user_goal_complete=false`、`user_obligations_verification=unverified`；`reported_delivery_complete` 与 `report_delivery_status` 单独表示报告交付。终端关系使用 `reported_observation_delivered`，不沿用科学目标已满足的关系。
7. a006 真测暴露宽引文的作用域问题：`original_text/source_refs` 可同时包含多个交付项，不能据此要求每个任务产物提供原生计算来源。执行来源要求使用已归一化、可追溯的本 Goal `quantity/minimum_evidence`；两者缺失才保守使用原文。原全文仍用于存证与最终核对，不删任何要求；否定只作用同一执行分句，不能覆盖另一明确肯定的真实计算要求。

## a007 真测后的同源限额修订

六次真实 ORCA 已完成，32 个候选均归档；五条观察却被额外的 `sources=1..16` 拒绝，实际记录仅 336–9,824 字节，远低于冻结的统一字节/产物预算。该限制不是科学判据，也不能防止无来源数值。

新 Run 显式选择 `reported-observation-2`：来源清单与产物引用共用 Run 产物额度和现有记录/总字节额度，接纳诊断版本为 `bounded-observation-admission-4`。版本 1 与缺字段继续使用原来源数量限制，不重新接纳历史被拒观察。无外部文件来源的任务元数据仅可绑定已归档 manifest 的精确 hash、记录索引、批准代码与 Attempt，明确记录为 `self_reported_manifest_value`，保留原 `sources=[]`；这证明报告值的来源，不证明其内容或原生计算。明确 ORCA、物理条件、资格及注册检查仍按前述规则拒绝伪来源。

观察推导值必须保留与实际成员标识的对应关系，聚合极值不能套用任意成员标签。输入生成限制与任务种子分别报告。a007 暴露的实际配对标签错误作为失败事实保存，不因其总体去重阈值仍满足而忽略；新提示只说明通用来源对应原则，不注入按题算法或答案。

## 直接验收

验证历史序列化/结果不变、真实 a005 已接纳观察的有限报告交付、显式原生要求不能被任务数据伪装、逐来源条件/未知/失败硬拒绝，以及终端必带未验证义务。原七题随后使用新不可变候选真测，并独立读取其实际科学数据；不把离线回放、有限报告交付或开发者检查冒称专门科学资格、正式三次重复或独立参考计算。
