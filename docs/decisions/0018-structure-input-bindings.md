# 外部身份、准备结构与首次科学基线

日期：2026-10-07。依据缺口闭合方案批次四、五和蓝图 §4、§5、§6、§10。用户已要求完成后续批次；本决定不清零历史预算或改写旧运行。

## 选择

纯文本入口使用显式启用的本地水/甲烷配置，保留原文，通过既有语义候选校验确认目标和条件。配置提供的 RHF/STO-3G、气相、中性单重态记为允许默认；明确条件和未知优先。未指定几何关系的能量问题仍需澄清。网络查询、结构准备、科学执行和模型调用各自有冻结许可和有限预算。

SystemInput 保存名称约束和 `geometry_source=prepare` 的输入获取意图。`structure.resolve` 仅查询官方 PubChem 有界字段，将原始响应与程序核验的水/甲烷身份保存为不可变 Artifact；`structure.prepare` 只消费经核验身份，经锁定 OPI/RDKit 生成初始 XYZ。两者均是有明确影响的 Step，不是即时只读查询。准备结构端口只证明声明范围内可用的初始几何，不能满足优化结构目标。

Run 的局部 `input_bindings` 保存 Request 版本、体系、用途指纹、Call/Result/Artifact 及 hash。每次消费核对冻结 Step、当前用途、明确选中的 Result 和来源文件。成功准备不改写 Request，也不追加 Artifact 白名单；旧版本或不相符来源不能启动科学计算。查询和准备均在预约后执行，固定 Call 的完整提交回执支持孤立产物/Result 接回；缺少证明时保留 unknown 与已占预算，绝不重新查询或生成来掩盖未知。

准备执行复用本地受管进程后端及全环境计算租约，保留句柄、期限、内存与进程树终止事实。身份查询单独限速，网络失败保留原始响应与诊断，没有模型猜 SMILES 或固定 XYZ 生产回退。

仅新输入获取 Run 使用“首份覆盖原始科学目标的科学 Plan”冻结科学基线；旧 Run 已冻结的空列表不重新解释。是否收取 Plan 修订预算依据已激活 Plan 历史，与科学基线冻结解耦。首次前置 Plan 后的自主修订仍累计，后续真正追加仍需原许可和剩余额度。

## 替代方案和验收影响

不把准备结果伪装为用户消息，不使用 `user_update=True` 填充几何，不泛化为同 Run 任意文件授权，不建设新领域对象或第二执行框架。相比改写 Request 和白名单，局部输入绑定能保存原始用户意图，并使版本、hash 与用途核验可审计。

验收覆盖纯文本零 ORCA 链、查询失败及身份冲突、伪造/跨体系/旧版本产物、准备与优化资格隔离、产物和 Result 提交中断、连续恢复不重复生成/计费、用户修改条件后的拒绝启动、前置修订计费和首次/追加科学基线。真实 PubChem、OPI、模型与 ORCA 分层记录；原阶段 B 验收保持独立。
