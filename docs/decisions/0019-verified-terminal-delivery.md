报告产物状态在 Run 收据及报告 JSON 中记录；不可变 Markdown 不嵌入自身发布状态或自身 hash，
避免写入时的 pending 状态永久留在已发布正文。只读查询报告产物时仍复核其文件 hash。
明确 resume 重开时保留原收据，重新检查事实/阻断/许可/余额后进入正常模型决策；没有新决策

同样先重新决策，不能仅因旧记录缺少新收据而直接执行剩余 Step。
