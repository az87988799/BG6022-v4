# 保持原范围的自然续作指令

2026-10-19，Code as Tools 步骤 5。用户明确允许修改阻碍当前目标的旧规则。

同 Run 开发续作消息明确要求保持原目标、条件、最低证据、权限和累计预算，但旧控制指令仅接受白名单中的精确短句，三次模型提案均被拒绝，未启动任何计算。这个限制阻碍自然续作，也浪费纠正额度。

允许严格有界的“继续既有任务、沿用原范围”句式。程序只接受有限的续作与保留语句组合；否定、添加科学条件、修改额度或许可的文字仍走原语义校验，不能作为控制指令消费。模型的 control-only 提案继续禁止携带 Request 字段、目标变更或自动选择。该入口只恢复当前许可内的决策，不授予执行权限、不生成求解内容、不改变原截止时间、不重置消耗。

不以宽松关键词匹配接受任何含“继续”的消息，也不为己烷或测试消息新增求解路径。少量正反例验证本契约；真实失败与后续源码版本、调用消耗分别保存。该开发续作不属于同一冻结候选首次通过或步骤 6/7 正式验收。
