# 原文作用域与当前目标证据

日期：2026-10-07。对应[缺口闭合方案](../reviews/2026-10-07-bounded-gap-closure-plan.md)批次一，落实蓝图 §4、§6.2、§8.5、§14。本文记录本次实现选择；验收结果另列，不授予新的真实执行额度。

## 问题与选择

初始目标只核对登记 ID，可能把明确的水目标绑定为甲烷。字段依据按整个分句扫描否定，既可能误拒绝“使用 RHF 但不执行”，也没有可靠地区分同一消息中不同体系的条件。查询目标修订后，旧直接绑定还可能遮蔽新计划的有效结果。电荷、多重度在部分入口被 Pydantic 转换后失去原始类型。

在现有语义规范化责任链中共用目标身份核验，按目标原文、已登记体系和有限名称/别名规则判断。背景溶剂提及不成为目标体系；范围外的明确名称保留要求，不自动替换为支持体系。字段引用关联真实用户消息及其命题作用域；程序定位唯一片段，重复片段须提供可消歧依据。否定执行与否定条件分别核对，未知不能由历史或默认覆盖。

新的候选协议显式升级为 `request-semantics-2`，局部区分告知与待答问题，并关联缺项。旧候选保留解析及只读复核能力；旧记录不补写新来源，新激活不再接受旧协议。是否等待用户由当前交付范围与实际缺项共同判断，登记告知完成不表示科学目标满足。

当前目标证据在一个共用函数中选择并复核，用于运行判断、模型事实及报告。原子 Request 修订只解除不适用的当前选择，保留历史 Result/Artifact；有效且无关的目标证据仍可保留。不按结果时间或目录次序挑选答案。

新命名约束还通过已有几何读取和水/甲烷组成规则核对实际 Artifact，不能仅信任 `water` 标签。语义提交、科学计划/预约及历史结果当前复用共用该检查。局部规则标识为 `named-target-1`；有 canonical identity 的用途快照保存这一约束，不把原文片段或别名当成新的物理条件。无该字段的旧用途快照继续使用原 `current-purpose-1` 内容，旧检查不重写。这是目标适用性检查，不宣称建立通用分子身份算法。

整数约束只针对电荷、多重度，在转换前拒绝布尔、浮点与数字字符串；合法整数及允许的显式未知保持原有含义。历史已经规范化的整数记录继续可读，不扩大到所有历史模型的严格模式。

## 替代方案与边界

不采用仅改提示词、整消息分子名集合、全局删除否定检测、按最新 Result 选证据或全模型 strict 模式。它们分别不能保障对象一致性、命题作用域、历史适用性或兼容性。本次沿用 Request、Run 内局部记录及既有提交恢复机制，不增加领域对象、交互状态机或科学判定链。

## 验收影响

覆盖初始/替换/后续目标绑定、条件来源与否定/疑问/确认、只登记零启动、严格整数入口、同 ID 查询和条件修订、无关更新、多目标与连续恢复。被拒候选不得激活 Request、改变许可或增加 ORCA 启动；历史来源可追溯，已有结果不能冒充新的物理条件。

新 schema/prompt 需要后续批次重新冻结并验证真实模型效果。离线脚本和合成结果只证明程序边界，不代表新的模型、PubChem、OPI 或 ORCA 验收。优化最终阶段科学资格、纯文本入口及真实验证仍按后续批次单独交付。

当前提示标识为 `agent-json-v17`。为保持原 12000 输入上界，缩短重复协议说明，并省略空结果表的解码说明；不提高调用限额，也不删除用户事实。告知及待答范围记录在既有修订语义中，报告单列登记完成；无科学执行意图的限制在修订与恢复期间持续生效，已有证据读取仍通过原 Tool 影响校验。
