# 后置能量交付引用关联已覆盖的计算义务

日期：2026-10-21。依据用户持续修复真实模型阻碍的授权，修复 a024 T5 已明确计算气相与 C-PCM 水单点能，却因后文“绝对能量（Eh）”不在两个 Goal 的计算引文范围内而反复拒绝的问题。

## 决定与边界

简化流程保留原来的逐位置、逐体系和逐条件覆盖检查。只有同一消息中可明确识别为纯交付列表的后置直接能量引用，才可关联此前已由必需通用目标完整覆盖的计算义务。关联要求体系、几何关系和物理量类型一致；并列环境的计算义务各自通过原显式条件证据检查。交付句和中间语句不能引入新环境、几何、额外计算或未知限定；无法确认仅为交付引用时保持原拒绝，不依赖模型显示名称或自由说明决定科学范围。

关联后，在对应 Goal 的显式最低证据中保留完整交付量词及其单位，并保存交付原句、准确消息位置与被关联计算义务的程序审计。原计算目标、环境、固定几何、来源、必需状态和科学检查不变；不额外创建重复 Goal，不替模型生成计算或解析程序。

此次移除重复位置门同时暴露一个原先被错误拒绝遮住的缺项：`ΔE=E(…)-E(…)` 的明确差量公式尚未形成独立覆盖义务。统一来源入口保留该完整公式，复用差量类型并要求必需目标的认证原文包含同一公式；公式中的溶剂是被引用计算的条件，不要求差量分析目标拥有两个互斥执行环境。完整差量交付句及 kJ/mol 等单位也进入显式最低证据；缺差量目标不能由两个绝对能目标代替。不计算公式、不猜数值或补科学资格。

只影响新简化流程的语义提交。旧 Run、原始模型响应、已冻结源码及已有结果均不改写。归一成功不代表真实计算成功或完整 T5 交付通过。

## 定向验证

用 a024 原始第三次提案和原请求建立带 SHA256 的离线 fixture，仅重绑测试消息身份；验证五个原目标原样激活、两个环境分别保留且 Eh 交付成为显式最低证据。反例覆盖缺失或错误环境目标、其他体系、新环境、新几何、额外点、未知限定及变换量。复用已有四项能量替代反例，不执行模型、ORCA 或全量回归。
