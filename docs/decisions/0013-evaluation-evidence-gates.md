# 评分、参考副本及执行冻结的局部门禁

日期：2026-10-07。范围为修复方案 F-07/F-08/F-09 及新增原始文本评测入口；不修改产品领域生命周期，不新增许可或科学能力。

原 pytest console 入口不能稳定导入 tests，采用一处 pytest `pythonpath = ["."]` 配置，继续使用官方 `uv run --offline --locked pytest`。不并存临时环境变量或多套路径修补。

历史独立参考的绝对来源身份保持不变，通过来源字符串和 SHA256 精确映射到受控仓库副本。只复制必要的小文件，不搜索猜测路径、不重新计算参考、不改变活跃 Run/Store 身份。每次读取验证相同字节；缺失或篡改仍不能通过。

评分由无持久生命周期的共享函数归类。明确失败优先于缺证据；pytest 和聚合器共同采用它。真实成功提案必须绑定自己的不可变请求/响应，前序失败传输也保留完整收据。usage known/unknown 只说明成本证据，不能取代响应身份；未知成本照旧保守占用。

执行冻结与历史静态复核分开。新 freeze v2 在任何正式调用前验证相关文件集合及 hash、产品实际导入根、Python、关键依赖的已安装文件身份和已参与导入文件、模型/prompt/token版本、实际有效配置。科学执行额外核 doctor 版本和 ORCA/MPI 字节。旧清单可继续静态复核，不要求审查机有 ORCA，不把 HEAD 相等作为版本代理。实际配置经 load_config/ORCA_AGENT_CONFIG 加载；不写死开发机路径。

新增十二个原始文本评测以独立 raw-text-cases 文件保存契约，调用既有生产 initialize_bundle 和 Agent。原 25 变体的期望和 hash 不变。当前可执行矩阵包含原 174 槽和新增 36 槽，合计 210 槽。既有甲烷 Opt 三次轨迹复用 raw 入口及优化后能量关系；执行开发门槛和累计预算复核未齐前禁止创建正式 freeze。不把脚本候选、未运行节点或离线证据记为真实语义/科学通过。

真实开发 N01 v3 暴露失败响应只保留 hash、诊断与成本、丢失 `message.content` 的证据缺口。现为既有 `ModelReply` 增加可选 `raw_content`（不进入 repr），只在完整提供方响应可严格解析并唯一定位 message 时保留原样文本。合法提案、非法提案 JSON、截断及其他可安全提取的失败均适用；不保留提供方异常、headers 或 reasoning_content，也不为旧失败补造文本。

原文最多 32 KiB UTF-8，JSON 转义后最多 64 KiB，完整响应收据仍最多 128 KiB。直接或 JSON 转义后的凭据匹配、非法 Unicode、超界内容均不保存原文；完整收据因嵌套缩进超界时拒绝提案，仅留下有界诊断、响应 hash 和既有 usage。转义扫描只用于保守排除凭据，不参与提案解析或修复。重复键、非有限值、超深度、围栏和非法 JSON 继续严格拒绝，失败原文不能成为可执行提案。

读取仅接受当前完整字段集合或明确列举的旧 14 字段完整集合；旧收据缺 `raw_content` 时在内存中视为 None，其他缺字段、混合形状和额外字段均拒绝。新原文需再次通过类型、字节与凭据检查，存在成功 proposal 时须严格解析为同一 JSON 值。旧字节、已结算 hash、累计预算和首次失败保持不变；恢复或重复读取不会新增 HTTP 或重复结算。本次新增离线 fake transport、原始历史收据及恢复反例验证，不能替代后续真实模型语义验收。

用户批准 v14 模型预算补充后，验收辅助程序采用第二次显式累计迁移：HTTP 1004→1050、tokens 6500000→6530000，ORCA 分类/总量及 USD 10 不变。原始额度、第一次批准 profile、批准记录和迁移回执均保留；新增独立批准文件及第二个不可变 before/receipt。第二回执绑定第一条已应用权威与本次迁移前完整账本，读取时核验两层来源，既有 known 消费不能删除或退款，unknown 仍保守占用且可经原结算链正常对账。

普通执行只接受最新已应用 profile；上一版仅供显式迁移的受锁读取，不能从无第一回执的原始 profile 直接跳转。沿用同一批次锁、先不可变快照/回执后原子发布，三个崩溃窗口重放同一字节，不创建新账本或重新发放额度。除 limits 与 limit_authority 外发布前后所有账目一致；之后新增合法消费或结算不影响重复应用的只读幂等性。选择该固定两层校验，避免双活额度及通用配额平台。新正式 freeze 纳入两份批准并绑定最新应用权威，旧 freeze 不改写、不因此获得执行资格。批准包的开发范围和原正式门槛仍独立生效；辅助程序及离线测试不代表实际迁移或新真实调用已发生。
