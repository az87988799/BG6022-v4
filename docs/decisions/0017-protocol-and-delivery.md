# 0017：有界模型恢复、逐目标交付与评测事实

日期：2026-10-08（Asia/Hong_Kong）

范围：缺口闭合方案批次三。沿用唯一 Agent 循环、Tool 注册定义、Run 预算及既有目标适用性检查；不扩大物理量、模型/ORCA 许可或真实执行额度。

## 问题与决定

1. 截断空正文没有可供格式修正的候选。冻结配置下停止该逻辑提案，不用相同模式和上限重复发送；普通完整正文格式错误仍受既有一次纠正限制，传输失败单独计数。历史收据只读，不重写错误类别或费用。
2. 对明确要求模型最终解释的轨迹，在发送边界为最终回答保留一次调用和决策机会，并披露实际剩余的纠正及 token 容量；token 预约按每次实际准备的上下文检查，不为未知的未来上下文强行预留最大值。已经进入仅最终回答阶段的调用不再预留另一次回答。不改变 Run 预算，不为普通只读请求强加最终解释预约。耗尽时继续给出确定性事实报告，不能标为模型完整交付成功。
3. 复用 `current_goal_evidence` 和科学适用性结果，生成无独立生命周期的逐目标事实行。当前请求条件与历史来源条件分别呈现，当前不适用的旧数值不能成为目标答案；读取观察、科学资格和目标完成分列。Context 与确定性报告消费同一投影函数，不新增科学判定器。
4. 评测分别记录可验证 HTTP 收据、接受提案、科学/查询输出和所要求的最终解释。已知失败优先；空正文的事实及语义轴为未验证。历史评分和收据不修改。
5. 测试进程身份文件在复现半写窗口后使用现有 `atomic_write` 发布；坏的最终 JSON 仍失败。空身份集合不证明进程已经退出，需结合创建时间、PID 或 Job 对账证据。该修复只改测试协作文件，不改生产取消语义。
6. 新上下文契约为 `agent-json-v18`；历史请求和收据版本不重写。先共享重复对象与条件，随后才缩短大型观察；紧上下文只展开当前 Plan/Goal 需要的 Tool schema，已校验待执行 Step 使用其 ID，全部许可工具的能力声明仍保留。可缩短重复动作示例，动作枚举及严格校验保持完整。大型目标观察保留内容 hash、字节数与 Result 来源；标量数值和明确未知单位直接呈现。
7. 新增权限字段为 False、预算字段为 0、System.identity 为空、geometry_source 为 registered 时，可省略新上下文字段；启用值及非默认获取来源始终可见。旧权限/预算字段、原文、目标、当前未知条件、历史来源条件均不因此删改。省略只影响投影，持久化对象与执行校验保持完整。

## 替代方案

不采用自动提高 token 上限、切换 thinking 模式、拼接截断 JSON、新建交付对象或独立评分账本。UTF-8 字节预约上界继续明确区别于实际 tokenizer 计数。所有 Tool schema 仍从注册定义派生。

## 验收影响

离线回归覆盖空正文截断停止与恢复不重发、正常格式纠正、最终解释额度、逐目标当前/来源条件及未验证观察、零接受提案真实形状收据分类、测试文件原子发布与坏最终文件。新增回放 fixture 明确标注合成或记录真实原始/派生 hash。真实模型的格式/解释可靠性和真实 ORCA 结果仍须批次六单独验收；离线通过不能替代。
