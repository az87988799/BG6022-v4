# 模型服务余额不足的明确诊断

日期：2026-10-21。范围来自 a027 最后一次请求的 HTTP 402；已有两个内部 ORCA 完成与气/水绝对能观察交付不因该模型服务失败撤销。

[DeepSeek 官方错误码说明](https://api-docs.deepseek.com/quick_start/error_codes/)将 HTTP 402 定义为余额不足；[官方余额接口说明](https://api-docs.deepseek.com/api/get-user-balance/)规定 `/user/balance` 返回 `is_available` 表示余额是否足以调用 API。本次开发核对已有一次余额检查回执；产品不新增自动余额查询、重试、服务商回退或充值操作。

现有传输异常分类将 402 记录为 `insufficient_balance`、`retryable=False`，恢复分类为 fatal，不进入模型纠正或传输重试。持久回执读取器仅接受这一新增类别，历史 `http_error` 原记录不改。没有 usage 的失败继续保守占用完整预约 token；不能由 402 推断免费、退款或零消耗。

报告保留模型回执的安全整数 HTTP 状态；最后一次模型失败为新增余额类别或历史 `http_error` + 402 时，明确说明余额不足、需充值或恢复服务后继续。已有 Request、Goal、科学结果、原始回执及未知用量不变。后续成功模型回执不会仍被描述为当前余额阻断。此变化不改变提示模板版本，也不回写 a027 的冻结源码或旧报告。

验证限定为 402 不可重试/错误正文不泄露、401/429 既有行为、新类别持久化与恢复后未知预算占用、以及新旧类别报告识别。无真实模型/ORCA 调用，无全量回归。
