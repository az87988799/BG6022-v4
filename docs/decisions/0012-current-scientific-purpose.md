# 当前科学用途、最低证据与几何谱系

日期：2026-10-07。对应修复方案 F-01、F-02、F-03；不扩展科学执行范围。

原 Result 的科学资格不能直接代替新 Request 的目标验收。旧实现遗漏环境、电子态、Goal 条件和最低证据，且把任意未来几何生产者视为目标体系谱系。问题影响历史复用、有限采样和优化后电子能。

采用局部 `applicability.py` 与 `minimum_evidence.py`，保留七对象和唯一解析/检查责任链。`current-purpose-1` 在计划、分析消费及目标验收使用同一条件函数；报告保留每次当前用途的缺失、冲突和最低证据诊断，不改写旧检查。

体系条件是该明确体系作用域的设置，可覆盖顶层一般设置；Goal 条件是附加约束，不能覆盖适用的体系或顶层约束。明确未知不取默认，关键条件的推断仍待确认。仅未声明的环境/电子态沿用现有已限定的 RHF 气相 profile，记录来源；方法、基组、电荷、多重度缺失仍未决。HF/RHF 在方法字段规范为 HF，RHF 的受限态含义同时受电子态约束。

旧结果省略环境/电子态时，仅从 hash 已复核的原始输入、固定 profile 和科学检查恢复，保存依据；当前请求不能反向提供结果条件。非气相、非 RHF 和当前范围以外条件保持未决。

`minimum-evidence-1` 是小型受控表，不是规则语言。现有 `converged_scf`、`converged SCF` 映射到实际 SCF 检查；旧文本 `original purpose and conditions must be preserved` 映射到当前用途判定；`all_initial_members` 检查实际必需成员。保留原文本、映射版本和逐项结果。未知要求、未知版本及不适用输出均未决，不新增稳定性计算。

多体系标量 Goal 保留原 Goal 但无法完成，要求明确逐体系目标；不得取第一个体系或通过删目标降要求。集合分析保留原成员清单与可选缺项。

几何按冻结 Step、Attempt、Result、产物归属与 hash 回溯初始根。计划拒绝跨体系未来引用，Store 消费再核验真实生产者；不以可改标签代替谱系。合法优化可改变坐标 hash。优化后能量只接受同次合格 Opt 的最终能量/结构或消费合格结构的同体系 SP；保留未收敛优化中仍有独立资格的普通电子能。跨 Run 来源无需位于当前 Plan。

纯 Plan 校验无法读取历史 Artifact，因而将直接引用的历史结构谱系交给 Store 在首次创建、修订激活及尝试预约三处核验；未来生产者的跨体系图仍在 Plan 中拒绝。只有完整合格优化谱系允许偏离原初始文件，任意已登记 XYZ 不能替代。结构自身的独立资格不依赖同 Result 另行发布 energy 端口。

未采用分别给目标、采样和计划加独立布尔判断的方案，避免重复相容性协议；未采用新领域对象或通用证据规则引擎。验收包括不相容/未知条件、Goal 冲突、最低证据缺失、多体系遗漏、伪造生产者、优化未收敛及合法历史/Opt→SP 对照。测试使用历史输出只读消费和明确标记的合成生命周期；不代表新的真实 ORCA 或真实模型证据。
