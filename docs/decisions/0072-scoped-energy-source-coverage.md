# 能量覆盖独立于程序生成的显示名称

日期：2026-10-21。依据用户持续根本修复真实模型阻碍的当前授权，修正 0069 与既有逐目标条件覆盖之间的耦合。

## 实际问题

a023 T5 首提案已经包含两个必需单点电子能目标，分别以同源明确条件绑定气相和 C-PCM 水，均保持固定初始几何。两个目标引用同一句“分别计算气相与ORCA C-PCM水环境下的单点电子能量”。0069 将摘要名称规范成该完整原文后，覆盖检查仍把显示名称当作单一量词解析：最后水环境修饰词使直接能量类型匹配为空，气相义务被误报缺失。

在临时目录中回放首提案，原样重现该拒绝；只将两个名称改成“单点电子能量”即可激活，其他五个目标及科学字段均未改变。原真实模型第三次提案也改用该名称后继续运行。不能把重复抄写量词当作新的科学证据或要求用户重述明确条件。

## 决定

对拥有可复核 `source-quantity-label-1` 程序审计的通用目标，覆盖检查不再从显示片段推断独立物理量，而是从该 Goal 完整、已认证的 `original_text` 提取自身能量短语。复用已有来源量词和逐目标有效条件入口，分别验证同源显式条件，再判断直接能量、差值或保留完整限定的字面义务。并列环境共用量名仍是多个独立环境义务，不拼造引文，也不把不同环境折叠成一个条件。

审计标记、规范值、完整来源字段及原提议标签必须相互一致；只给出“气相”而未包含能量的目标不能从待覆盖请求中借来量词。没有程序规范审计的原逐字名称继续使用原严格匹配路径，防止已有变换量、阈值、计数或被禁止的物理量替代原始电子能。源消息、范围、体系、固定几何、必需状态及实际条件仍须通过原检查。

不扩展执行许可、最低证据或科学资格；不增加任务求解器，不修改原始响应、活动 Run 或旧检查。a023 保持原冻结源码继续运行；新源码在后续候选中显式捕获。

## 验证

保存首提案参数和原请求的无凭据 fixture，含原件路径及 SHA256；离线仅重绑测试消息/片段身份。原样提案激活且零模型、零 Tool、零 ORCA。定向反例包括缺气相、缺水环境、两个目标错用同一环境、去除差量交付目标、仅引用环境词、外来消息，以及归一化能、阈值、次数替代能量；既有电子能覆盖反例继续验证。仅归一通过不代表科学结果或 T5 已完成，真实执行和交付独立报告。
