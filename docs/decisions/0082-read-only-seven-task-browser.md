# 0082：七题历史记录的只读网页入口

日期：2026-11-12（Asia/Hong_Kong）。用户明确授权将七项测试接入现有网页，查看结果、脚本、ORCA 输入输出并下载原始数据；直接读取已有记录，不重新运行模型或计算。

## 问题与选择

现有网页只浏览一个 `data_root`，七题代表运行分散在独立验收和开发工作区。把 Run 或 Artifact 复制到默认 Store 会改变来源关系；切换执行配置、创建可恢复的导入 Run 或重跑计算也不符合本次要求。

本次采用固定的本机目录清单关联既有 Store 与确切 Run ID，在原网页增加独立只读视图。清单是开发者部署资产，不从模型、附件、HTTP 参数或测试原件推断访问范围。路径相对仓库根，拒绝越界、符号链接、junction 和设备路径；缺少本机原件时明确不可用，不自动下载、生成或补算。

## 契约

- 仅增加 `/api/acceptance/` 的 GET 读取接口，沿用现有 loopback、同源和本地 token 边界。浏览器只传固定任务、版本和 Artifact ID，不能指定文件或 Store 路径。
- 历史数据仅通过原 Store 读取方法、Run 产物访问范围和证据读取/下载校验访问。每个来源固定原 Run 与已保存报告的 SHA-256，报告必须与 Run ID、历史状态和交付状态一致，不在打开页面时重建或重新解释历史报告。每次请求的所有授权读取使用同一份已核验 Run 字节，避免校验后重新读入不同权限。只读适配不创建目录、锁、Run、审计或交付文件，不调用模型、执行器、转换或恢复。
- 只读面板没有提交、追问、继续、暂停或取消入口；只读命名空间不注册这些动作。默认工作区的正常计算界面保持原有许可和控制行为。
- 每题明确标记代表候选、Run、原运行/交付状态及已知缺口。T5 保留 a026/a027 两个独立来源，不合并方法或基组。不同历史候选的数值存在不表示同版本七题通过，不改变原科学资格或目标完成状态。
- 文件目录分页，脚本、输入、输出和数据按已有角色/文件名提供浏览分类；分类不授予科学含义。逐页核验完整性，读取与下载仍核对原 hash。单文件下载沿用 16 MiB 上限；更大文件显示限制和本地位置，不通过 GET 隐式转换或打包。
- 下载直接返回已有原字节，不新增 ZIP；公开清单不包含模型原答、凭据或任意目录扫描能力。

## 验收与范围

定向离线测试覆盖只读接口与原工作区不变、执行入口拒绝、任务/版本/Artifact 越权、路径/链接与 hash 损坏、分页和缺失原件、二进制下载及已有网页回归。本机只读核对八个代表 Run（七题，T5 两版），浏览器核对七题入口、结果、脚本/输入输出及下载。

验收不调用真实模型、ORCA、任务 Python 或科学转换，不重跑七题，不修改历史配置、预算、结果或冻结候选。界面交付与七题科学/端到端验收分别记录；完成后提交推送，等待用户验收。
