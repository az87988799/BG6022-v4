## 决定

新 Run 冻结 `workflow_policy=simplified-1`。缺少此标记的旧快照保留历史规则和序列化形状，不升级历史结果。

1. 用户原文由程序提供稳定片段引用；模型可引用片段而不反复抄写。明确的几何关系由程序绑定，通用目标不因旧采样专用关系字段误入旧路径。环境保留原文和规范映射，仍检查实际运行条件；不靠少量自然语言别名排除明确水环境。
2. 已授权的方法、基组自动选择保存理由和来源，官方资料检索为按需而非每次必经。有检索时仍验证来源，不能伪造检索支持。电子态缺项或明确冲突不猜测。几何准备可独立进行，计算前须完成影响科学执行的选型。
3. 模型用明确生产 Step 和输出口/文件键表达依赖，程序在真实产物就绪后解析 ID/hash，验证归属、权限、类型及所需资格。允许一次显式规划写入与消费步骤；不能选择不明确的“最新文件”，不能因文件名后缀赋予几何资格。未覆盖目标由程序保留为 gap，不能删除或宣称满足。
4. 文件语言等由明确工具和产物类型补齐；显式矛盾仍拒绝。简短失败修复引用同时覆盖 Python 与原生 ORCA 输入，继承同一逻辑步骤的未变合同。输入、代码、每次尝试和失败均独立保存；无有效修改、执行未知或未确认停止时不得重跑。
5. 已批准电子态和冻结资源在原生输入遗漏时写入最终执行字节，保存原稿、最终输入及补入记录；显式不一致不覆盖。原生语法错误仍由程序校验或 ORCA 返回，不自动重排未知语法。程序不编写任务科学算法。
6. 当前失败优先给出有界完整短回溯或尾部异常与相关脚本帧，不只展示无错误原因的前几行。重复读取和历史正文缩减，不提高原上下文上限，不删用户最低要求或原始证据。
7. 空正文且输出截断允许至多一次有界纠正，要求较小下一动作；计入原调用、token、纠正与期限预算，原失败保留。认证、权限及其他不可恢复错误不无条件重试。
8. 独立、已计划的 Python 执行与失败重试分别计数；总分析、逻辑步骤、同输入/同逻辑尝试、运行期限及资源上限继续有限。改 ID 不能恢复同一失败的免费额度。任务可明确分段保存结果，不把串行多计算假定为单作业耗时。
9. 计算停止后，收集有自己的有限期限；只在确认原计算静止后允许只读收集，不被已到期计算 checkpoint 再次中断。保留未知状态、收集失败和资源占用事实，不能启动替代计算或释放未核实租约。

不新增求解工具、多 Agent 产品架构或结果资格。实现采用现有对象、Tool、责任链及局部帮助函数。
