# 查询命中的文档窗口保留代码格式与来源

日期：2026-10-21（Asia/Hong_Kong）。

a025 的官方文档查询成功归档了完整 NMR 手册，但 HTML 阅读器把代码块换行压成空格，段落匹配后又固定取前 1800 字符。真正命中的后部语法无法通过改变查询词读到。其后一个新检索结果因附带完整导航列表超过现有知识投影阈值，被整个压成 hash；这不同于已经修复并持续可见的执行失败日志。

保留 HTML pre/code 的换行，普通段落和表格继续原规范化。长段落按查询词命中的连续窗口选择，优先完整行；超长单行也按命中词选字符窗口。仍最多三个片段、每片段 1800 字符、总计 5400 字符。返回转换视图、原段落、字符及行范围、截断事实；可显式指定有界段落和起始字符继续读取，越界拒绝，不猜测或拼补代码。一个查询仍只有一个受限 GET，官方来源、1 MiB 文档限制、权限、累计成本与原始文档字节/hash不变。新阅读视图版本不回写旧 Result。

上下文在现有知识投影额度内优先保留查询结果、原摘录、文档和摘录 hash、覆盖范围及归档引用；导航与重复元数据不再挤掉最新摘录。省略明确记录，原 Result 和完整文档仍可查询。上下文不读取文件或联网，不增加总输入上限，不把摘录或语法示例当执行授权或科学证明。

验证限定 a025 已归档 HTML 的离线回放、代码行窗口与显式续读、原有表格身份及网络/权限边界、导航过长时的知识投影。只提交小型通用 HTML fixture；不向活动 Run 注入正确输入或科学求解，不启动模型或 ORCA。离线可读性改善不代表科学任务已完成。
