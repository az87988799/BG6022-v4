# 0003：局部检查版本升级与恢复结果关联

日期：2026-10-06；依据阶段 A 最小修复方案 R-01～R-05。本决定不扩展科学方法、预算或执行后端。

旧检查将全文件最后一次 SCF 成功与最终能量组合，不能保证它们属于同一几何/SCF 片段；修复改变科学判定，因此当前新检查版本为 `orca-hf-2`。共用声明供新 Request 的目标、科学 Tool 和新 Check 显式使用。模型字段缺省仍表示 `orca-hf-1`，旧文件读取不能隐式升级。历史 Request/Result 和原检查保持原字节；只读复验追加独立记录。旧 Run 可查看、取消、对账和补收；继续科学执行前必须经过规则复验，本次不提供通用迁移机制，也不通过新 ID 重置预算。

未知执行 Result 只是当时事实，不能因其存在就阻止终止确认后的收集。Result 增加可选 `supersedes_result_id`，默认空。仅同一 Run/Step/attempt 的单链替代合法，必须存在唯一末端；孤立候选、分叉、循环和跨尝试关联拒绝。保留全部 Result，新 Artifact 和 Result 先保存，再原子更新 Run 的当前/历史引用，最后结算或释放额度。已结算的历史 unknown 状态只补收、不重复计费。终止确认不赋予科学资格，无法可靠证明正常完成时只保留观察与限制。

选择此局部关联而非改写旧 Result，是为了保护当时事实并处理恢复途中再次中断；暂不建立通用版本管理或迁移平台。受影响验收为准备失败的确定未启动结算、SCF 片段绑定、恢复补收和幂等、离线取消、规则及 ORCA 版本门禁。ORCA 启用版本仅为精确 `6.1.1`，与第三方最低兼容要求分列。输入生成和原生进程管理不变，新增证据由故障测试和历史真实产物只读回放提供。
