用户在本次实施中进一步明确：“如果旧规则会阻碍任务，可以直接修改，以现在的目标为准”。因此，与当前通用任务目标冲突的旧专项限制直接按本目标调整并同步契约/测试，不重复请求冲突许可；原始失败、已发生用量及实际验证范围仍如实保留。

## 问题与选择

已有受管 Python 可以生成观察和文件，但报告未完整展示这些观察，整体科学状态可能掩盖未检查输出；多源观察把不同几何也当作条件冲突，无法准确表示有限候选比较。界面还缺少生成脚本、内部计算进度与验证缺口。模型结束失败时，已有事实也必须可直接交付。

继续使用 Request、Plan、Step、Tool、Run、Result、Artifact 和现有单协调者。通用观察扩展可选公式、派生产物及逐源条件，所有绑定通过归档 hash 核对。不同几何分别保留；方法、阶段或其他比较条件冲突明确记录，不能静默挑选一个成功值。格式、来源存在和进程结束不授予科学资格，已有科学解析与检查链保持唯一，不新增构象工具、专用生产解析器或隐藏求解算法。

逐输出显示科学检查、通用观察验证覆盖与来源问题，目标满足、报告完成和科学通过分别判断。候选、失败、排除原因与搜索范围放在任务生成的通用数据/文件内，报告原样呈现并限定结论；不能因为报告生成就满足强制科学条件。模型预算耗尽或解释失败仍保留确定性报告与停止原因。

Web 使用既有只读接口读取归档事实并提供受控下载；脚本分析、绘图、转换仍通过明确 Python Step 记录成本。只读状态、脚本预览和证据查询不启动任务、转换或模型调用。

候选几何准入扩展通过新 Run 冻结的 `NativeInputPolicy.allow_task_geometry` 显式启用，默认 false。仅 Python SDK 且 Request/System/Step/相关 Goal 没有固定几何关系限制时允许派生坐标；原始 Artifact/hash 不变，候选必须保持原子数和有序元素，逐候选保存实际几何 hash 与来源关系。该准入不证明拓扑、同元素原子映射、立体化学或构象质量；这些限制随观察/报告披露，不能授予科学资格。旧配置不获得该能力，原 fixed_initial/optimized 用途检查继续严格执行。

## 替代方案与验收影响

- 不采用逐性质专用工具/解析器，也不把任务算法写入 SDK 或提示资料。
- 不采用整个 Result 的单一通过标签代替逐输出状态，不由脚本声明科学通过。
- 只运行改动相关的必要定向检查。真实开发验证限定为自然语言己烷构象任务，独立核对原始能量、结构、条件和排名；所有失败与消耗保留，不进入步骤 6/7 的正式跨任务验收。
- 不覆盖历史 Run、原始几何或旧检查事实，不增加执行权限或变更容器边界。

本次退出条件及真实验证限制记录在 `docs/acceptance/code-as-tools-step5/report.md`，交付后等待用户验收。

## 首次真实任务暴露的接入问题

live001 在 3 次模型调用、零 ORCA 后有界失败：一般分子的 `sampling`/`sampling_check` 同名观察目标错误进入旧专用采样意图守卫。一般目标应先按通用观察契约分派，既有输入、只读、知识和严格科学检查路径不变。用户要求的交付项仍保留在目标和数据中，不自动升级成额外科学资格规则；实际明确最低证据不可删除或降级，非法引用须由模型纠正提案，程序不改写原回答。另补实际内部输入的只读下载授权：仅可信原 Attempt/回执绑定、归属与 hash 均通过的文件可读，未知生产输出不自动公开。原失败/用量保留，新源码与提示 v61 单独冻结再做一条有界真实验证；不重放或修改旧 Run。

live002 为 waiting_user/partial（2 次模型、零 ORCA），模型要求确认常规步骤的几何关系。发现输入获取指引无条件要求 SP/Opt 澄清，与一般任务的自主常规步骤选择冲突。v62 将其限定为适用的旧单一科学目标：用户未指定单一几何关系的一般任务可省略该标量，按许可选择流程并保留每项实际几何关系；明确指定的物理量、几何关系、条件与证据要求不变。新增反例约束旧采样规范继承优先，不能靠补 quantity 或吞掉 analysis_goal_ref 丢弃候选、阈值和强制要求。第三条开发输入明确重申常规步骤自主选择，不提供算法、Plan、代码或 ORCA 输入；实际结果与前两条分别报告。

live005 保留原 Run 的增量修订/控制入口修复续作后，脚本完成但 4 项 SDK 请求因缺显式波函数类型而被准入拒绝；模型仍未获得能量，后续修复回复在 24,576 输出上限截断。SDK 拒绝响应必须有界归档并形成 Tool 诊断，不能因为脚本捕获异常就隐藏原因；请求次数不能写成实际启动次数。提示 v65 明确既有 RHF/RKS 准入字段、逐成员失败原因和全部结构保留，不加入搜索算法、输入模板或分子特例。
