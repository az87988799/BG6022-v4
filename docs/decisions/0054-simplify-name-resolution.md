# 简化名称查询，取消别名二次取证门槛

日期：2026-10-20（Asia/Hong_Kong）。

用户明确要求取消“用户原名必须在 PubChem 同义词或 Wikidata 中文标签/别名中精确命中”的步骤，并要求以简化流程、先跑通为当前优先事项。本决定取代 0034、0052、0053 中与该步骤相关的要求；这是用户对已有实现选择的明确调整，无须再次确认。

## 问题与本次范围

正式 T2 已查询到 CID 8058、分子式 C6H14、SMILES CCCCCC，但因原名“正己烷”未命中额外同义词/交叉引用而失败。该失败属于名称映射门槛，不是 ORCA 或分子图解析失败。精确中文别名收录不能作为所有一般分子计算的必要前置条件。

本次只修改这项已明确授权的门槛，并审查其他因协议或额度限制而中断的历史案例。其他候选简化项先按真实证据列出，不在本次顺带改写用户目标、运行预算、执行隔离或科学成功标准。暂不调用真实 LLM，不启动正式批次。

## 新流程

1. 保存用户原名、原文出处、实际查询名及其来源；模型提出的翻译仍记为推断。
2. 一次受控 PubChem 性质查询返回唯一候选，取得 CID、SMILES、分子式、电荷等。
3. 校验返回结构可解析、组分及分子式/形式电荷自洽；用户原名中明确附带的分子式仍须相符。
4. 成功后允许使用该候选进入已有几何准备链，不再请求同义词或 Wikidata，也不要求它们提供中文原名匹配。
5. 身份输出明确说明保证范围：所查询候选及其结构信息通过检查；推断的名称翻译未进行额外独立认证。不得将省略的检查记成已通过。

已有明确歧义、冲突、多候选、无效结构及未确定立体化学仍按其实际影响处理。初始几何和后续执行的文件绑定继续使用现有链路，不新增求解工具、分子白名单、领域对象或开关。

通过现有身份契约和检查版本区别新行为与历史行为。旧 Run 的已冻结身份契约、旧检查结论、失败和预算保持原样；不能用本次放宽自动把历史失败改为成功。新身份检查不扩展能量、频率或其他物理量的科学资格。

具体使用 `general-identity-3`、`structure-identity-3` 与 `structure-prepare-3`，已有 v1/v2 体系继续选择原检查。尚无身份对象、从未冻结身份契约的请求，在首次生成身份时使用当前 v3；不额外增加 Run 配置字段或运行开关。新提示版本为 v75，历史提示版本仍可读取。

## 验证与退出条件

- 离线回放真实 T2 已归档的 PubChem 性质响应：新契约下只需一次查询回执即可取得候选并进入几何准备校验；不发起额外网络请求。
- 覆盖非英文查询别名、明确尾随公式、公式冲突、多候选、坏结构/电荷、旧契约兼容和下游输入绑定。
- 运行相关身份、几何准备、请求规范化及工具目录回归，记录源码与结果。模拟 HTTP 回执或执行边界不能冒充真实查询、真实 ORCA 或模型自主成功。
- 提交并推送本次相关改动，报告剩余约束和未验证项，等待用户验收。

## 未采用方案

不新增正己烷等特定分子的对应表，不把模型翻译标记为用户明确名称或数据库已认证别名，不删除旧证据，也不通过提高所有预算掩盖协议开销。
