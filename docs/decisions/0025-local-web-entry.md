# 本地网页入口与交付边界

日期：2026-10-08。用户要求按本地网页方案执行，并在本轮明确选择“采用方案中的网页生命周期”。实现状态见本批验收记录，不以本决定代替验收。

## 选择与替代方案

保留 CLI，增加 FastAPI + 静态 HTML/CSS/JavaScript 的薄入口，使用 lifespan 管理单个前台服务。没有数据库、任务队列或第二个 Agent。相比仅提供只读网页，此选择允许用户从网页显式提交和继续；相比独立前端构建与后台服务，减少部署依赖。

HTTP 请求不等待整个计算；执行线程只调用既有 runner.execute，Run 协调锁和全环境资源额度仍是执行权威。浏览器关闭不会结束前台服务。服务启动不扫描并恢复任务；重复提交返回原 Run，不能通过刷新重置预算。服务正常退出先停止接受启动，发送暂停，按既有任务期限收集，等待有上界。异常退出由原 Windows Job 清理，未确认状态仍需显式对账。未完成旧验收 Run 不通过网页绕过原批次账本。

只监听 127.0.0.1；校验 Host、Origin 和本地访问令牌。令牌只用于当前本地服务，不是模型凭据。报告使用 build_report 的受控事实投影；模型自由 reason 不作为回答。证据 API 绑定 Run 内登记的 Artifact，复用现有 reader 与 hash 校验，下载只传输已核对字节。页面全部采用文本渲染。

## 兼容接口与消息

保留 initialize_text、execute、commit_candidate、build_context、Tool 注册、终止交付与 CLI 参数。提取 schema 投影纯函数，保留 context._schema 兼容别名；不改变 v25 提示与调用结构。共用入口接收用户文本、持久提交键及 Run ID；不接收任意路径、shell 或预算修改。

消息去重按持久消息 ID 和内容匹配；重用 ID 改写内容拒绝。待处理消息最多 24 条；保留历史最多 512 条，达到存储上限明确停止而不清空历史。读取分页；模型继续使用已有有界上下文与同一 Run 预算。会话只做 Run/消息引用索引，不拥有执行状态。

## 后续科学与知识合同

偶极矩必须包含向量、模长、单位、结构阶段、方法/电子态、原始定位及检查版本。优化后性质须绑定已检查结构；证据不足时仅能通过显式单点 Step 补取，查询不能隐式启动。未实现/真实验证前不启用科学端口，不给历史输出自动升级资格。

知识回答需要独立非科学交付目标，在同一循环内计量；检索作为注册 Tool 保留 URL、时间与摘录。模型直答不等于联网能力或科学通过。首批网页如未接通此合同，明确显示未提供，而不把知识问题转换成科学成功。

同步蓝图 10.3、12、14；保留第 13.3 节和阶段 B 所有旧义务。新增重复提交、双客户端、CLI 竞争、消息重发、超过 24 条历史、只读无执行、来源/令牌、越界下载、刷新/重启、退出暂停测试。离线与真实验证分别报告。完整首版仍需偶极矩、知识检索和新候选真实验收，网页局部演示不能代替这些退出条件。
