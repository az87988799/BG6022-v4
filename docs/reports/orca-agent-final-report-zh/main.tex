\begin{abstract}
分子势能面探索需要在结构准备、电子结构计算、收敛判断与后续采样之间反复作出决策，固定脚本难以直接适应开放的科学需求。本文提出 Auto-ORCA，将大语言模型的任务规划与代码生成能力连接至受管理的 ORCA 执行环境。系统采用单一决策循环，将科学目标与可修订计划分离，通过通用工具校验并执行生成的 Python 和 ORCA 输入，再依据真实输出组织后续行动。为测试 Agent 的任务规划、代码生成、计算组织与结果处理能力，设置乙醇结构优化与振动频率、正己烷候选构象能量、正丁烷二面角扫描、丙酮垂直激发、乙醇环境电子能量差、HCN 核磁屏蔽及甲醛极化率七个问题。按 ORCA 计算正常完成并产生数值结果的口径，六项标记为成功，计算成功率为 $6/7=85.7\%$。乙醇优化收敛并获得 21 个正频率、0 个虚频；正己烷完成六个候选几何的单点能量比较；丙酮获得五个单重态激发能；两种基组下 CPCM 水环境相对气相的电子能量差分别为 $-18.276507$ 和 $-16.607972$ kJ mol$^{-1}$；HCN 获得三核完整屏蔽张量。正丁烷六个约束优化点计算成功，但实际二面角仍待独立核查；甲醛尚无极化率数值。结果支持通用工具与生成代码组合执行多类 DFT 任务的可行性，完整势能面结论仍需进一步的几何验证与采样证据。
\end{abstract}

\section{引言}
分子结构、构象稳定性与反应路径和势能面紧密相关。密度泛函理论（density functional theory, DFT）通过电子密度描述多电子体系，Kohn--Sham 框架为实际电子结构求解提供了基础\cite{hk,ks}。然而，单次求解只回答特定方法、几何与环境下的问题。势能面研究还需要组织结构优化、振动分析、候选比较及约束扫描，并根据中间结果决定下一步计算。方法和基组选择、电荷与自旋设定、结构准备、收敛诊断以及结果解释共同决定计算的有效性。

实际研究中的困难往往出现在步骤之间。一个已经完成的优化可能仍需频率检查，若干单点能量需要与各自几何一一对应，环境能量比较则要求保持共同条件。当任务不能直接套用已知协议时，研究者需要编写新的采样和分析程序。自主计算系统因而需要将自然语言需求、计算执行和科学证据连接为持续的决策过程，而不是只生成一个输入文件。

本文提出 Auto-ORCA，其完整名称为 \emph{LLM-Guided Autonomous Exploration of Potential Energy Surfaces Using DFT}。系统基于 ORCA 与 ORCA Python Interface（OPI）\cite{orca2020,orca6,opipaper}，通过单一 Agent 决策循环组合固定通用工具与现场生成代码。科学目标及最低证据要求独立保存，模型提出计划与任务程序，受管理工具负责实际执行并返回可追溯结果。

本文围绕三个问题展开：生成代码能否表达不同的分子计算任务，统一执行入口能否获得真实数值，以及这些数值能够支持何种科学结论。为考察 Agent 在这些环节上的能力，本文设置七个具有不同操作要求的测试问题。结构优化、构象比较与二面角扫描构成势能面相关测试；激发态、环境效应与响应张量则用于检验同一计算机制对其他性质的适应能力。研究重点是自主计算的组织与验证，不提出新的电子结构近似。

\section{相关工作与研究动机}
\subsection{从可追溯工作流到语义工具组合}
计算化学自动化首先需要解决的是执行的一致性。结构文件如何传递、输入采用何种条件、输出来自哪一次计算，以及异常终止后保留哪些证据，都会影响结果能否复核。ASE 以统一的原子结构与计算器接口连接不同模拟程序，AiiDA 将计算过程与数据来源联系起来，Atomate2 提供可组合的材料计算工作流，cclib 则支持不同量子化学软件输出的统一解析\cite{ase,aiida,atomate2,cclib}。这些工作共同建立了一个基础：自主决策应建立在明确的执行接口和可追溯数据之上，语言模型并不替代数值求解器与领域解析程序。

固定工作流适合计算条件明确、步骤依赖稳定的任务。例如，先优化结构，再计算频率，最后对所得结构计算单点能量，可以作为一种可重复使用的协议。但研究问题并不总能在执行前确定完整路线。优化得到的新构象可能要求重新比较候选；频率分析可能显示需要继续处理的几何问题；某个约束点的输出也可能使原定扫描范围失去充分性。此时，自动化需要理解步骤与科学问题之间的关系，并选择下一项有助于减少不确定性的操作。

语义工具组合把自然语言需求转化为既有工具的选择、参数与依赖，使用户能够以物理量和条件描述任务。它保留了专用工具的明确行为，但表达范围受工具目录限制：新的采样方法或跨结果分析若没有对应接口，仍需扩展工具实现。因此，从固定协议到语义组合的变化，主要是把路线选择交给模型；进一步引入任务代码，则允许模型表达有限循环、候选筛选和确定性分析。三种方法构成任务表达能力的不同层次，并不意味着后一种可以放弃前两种所要求的来源追踪和输入校验。

\subsection{语言模型 Agent 与闭环任务代码}
ReAct 将推理与行动交替组织，强调通过外部观察更新后续操作；Toolformer 研究模型学习使用工具的能力；Reflexion 则通过语言反馈支持任务修正\cite{react,toolformer,reflexion}。在化学领域，ChemCrow 将语言模型连接至专业工具，Coscientist 探索了模型协调化学研究操作的方式\cite{chemcrow,coscientist}。这些研究说明，模型可以承担需求解释和操作组织，但工具调用本身仍需要明确输入、可检查输出及领域知识支持。

对于电子结构计算，仅生成语法正确的 ORCA 输入仍不足以形成自主探索。输入描述的是某一次求解，而科学任务常由多个相互依赖的计算构成：待优化的几何来自哪里，下一步使用哪一份结构，多个能量是否具有相同条件，以及当前证据是否足以支持停止，都超出了单个输入文件的范围。闭环系统需要在计算之后重新评价这些问题，并将输出中的有效信息反馈给计划。AutoDFT 将规划、监控、恢复与后处理纳入闭环，为结果驱动的自主 DFT 提供了相关方法参照\cite{autodft}。

任务代码为这种闭环提供了较灵活的表达方式。模型可以生成一个有限程序，将几何变换、计算请求和结果分析组合起来；程序执行后返回实际产物，模型再依据这些产物决定是否需要补充操作。其关键并非一次生成更长的脚本，而是保留每个内部计算与原始目标的对应关系。例如，构象比较程序需要同时保存候选几何和能量，使排序能够回到真实结构；扫描程序则需要使目标标签、优化后几何与实际二面角相互对应。代码是组织算法的载体，计算回执与原始输出才是执行已经发生的证据。

这种开放表达也引入新的要求。程序可能包含多个内部计算，单次工具调用的成功不能代表全部子问题已经回答；脚本能够提取一个数值，也不能自行证明该数值属于所需的物理量。因此，Auto-ORCA 将任务算法交由生成代码表达，同时通过共同执行入口管理计算条件、资源消耗和产物来源，使程序的灵活性与可检查的执行事实保持连接。

\subsection{科学证据的对应关系与本文定位}
自主计算的评价应首先确认结果回答了哪个问题。Lee 与 Rondinelli 的自主多参考量子化学研究强调，计算收敛与电子态身份需要分别考察\cite{multirefagent}。如果没有确认所得态与目标态的对应关系，即使输出具有完整能量，也不足以直接进入目标性质的误差评价。这一研究提示，自主电子结构计算需要同时关注操作是否完成以及输出是否对应目标。本文将这种证据对应关系用于 DFT 任务的讨论；多参考求解、活性空间选择与电子态自动识别不属于本文已验证的能力。

在势能面相关任务中，对应关系表现为结构、条件与数值之间的联系。收敛优化结构需要结合振动信息解释局部稳定性；候选电子能量必须对应实际保存的几何；扫描能量需要与经过确认的构型坐标对应；跨环境比较需要保持指定的共同几何和电子结构条件。对于响应性质，还需要明确张量的坐标系、单位以及是否经过参考换算。数据的可发现性与可复用性有助于开展这些检查\cite{fair}，但材料齐备本身并不替代科学判断。

据此，本文关注三个相互连接的研究缺口：开放需求如何转化为有限且可执行的计算程序；计算成功或失败后，证据如何继续支持目标保持与计划调整；最终报告如何把已获得的数值和仍然缺失的验证清楚地对应到原问题。Auto-ORCA 以分子 DFT 任务为研究范围，通过单一决策循环、通用工具和生成代码研究这些问题。后文的七个测试用于检验 Agent 组织真实计算的能力；结构与性质结果同时用于分析该能力目前能够支持的科学结论。

进一步比较不同自主计算方案时，需要共同的任务定义、输入结构、最低证据要求和资源条件。计算覆盖、性质误差与运行成本回答不同的评价问题，应保留各自分母与适用范围。本文采用明确的问题级计算成功口径呈现已有结果，并在每个问题中说明数值的科学含义，为后续受控比较提供可复核的起点。

\section{科学任务的理论基础}
\subsection{势能面、结构优化与局部稳定性}
在 Born--Oppenheimer 描述下，给定核坐标 $\mathbf R$ 及电子结构条件 $\theta$，以气相基态 Kohn--Sham 能量为例，其基本组成可示意写为
\begin{equation}
E_{\theta}(\mathbf R)=\min_{n}\!\left\{T_{\mathrm s}[n]
+\int v_{\mathrm{ext}}(\mathbf r;\mathbf R)n(\mathbf r)\,\mathrm d\mathbf r
+E_{\mathrm H}[n]+E_{\mathrm{xc}}[n]\right\}
+E_{\mathrm{NN}}(\mathbf R).
\end{equation}
其中 $n$ 为满足电子数及指定自旋条件的密度，$T_{\mathrm s}$、$E_{\mathrm H}$ 和 $E_{\mathrm{xc}}$ 分别表示非相互作用动能、Hartree 能与交换相关能，$E_{\mathrm{NN}}$ 为核间排斥能\cite{hk,ks}。实际复合方法与溶剂模型还包含相应修正项。泛函、基组、电荷、多重度和环境共同定义实际求解条件。因此，能量必须与方法及几何一起报告；改变条件后，绝对能量不能直接作为同一势能面上的数值比较。

结构优化寻找势能面上的驻点。收敛判断依赖能量变化、梯度与位移等数值标准，驻点的局部性质还需通过振动分析判断。质量加权 Hessian 为
\begin{equation}
H^{\mathrm{mw}}_{ij}=(m_i m_j)^{-1/2}
\frac{\partial^2 E}{\partial R_i\partial R_j},
\end{equation}
其中 $i,j$ 遍历笛卡尔分量，质量按对应原子重复。振动子空间中的正本征值对应实振动频率。非线性 $N$ 原子分子具有 $3N-6$ 个振动自由度；乙醇含九个原子，因而对应 21 个振动模式。平动和转动模式需与真正振动分开解释，无虚频支持所得结构的局部稳定性，不能穷尽其他构象。

\subsection{候选比较、约束扫描与环境效应}
构象研究包含候选产生、几何处理与能量评价等不同环节。单点计算得到固定几何 $\mathbf R_i$ 上的 $E_{\theta}(\mathbf R_i)$；优化则允许核坐标变化，两者回答的问题不同。GFN2-xTB 与 CREST 等专门方法说明，构象采样与筛选本身具有独立的算法需求\cite{gfn2,crest}。本文的正己烷结果仅涉及已保存候选的 DFT 单点比较，不据此推断完整构象空间。

约束扫描在保持指定内部坐标条件的同时优化其他自由度。输入角度是计算指令，实际角度应由最终几何重算；对于周期坐标，可用包裹到 $(-\pi,\pi]$ 的角差比较目标与结果。能量曲线的横坐标必须来自可信的几何对应，才能进一步讨论极小值与势垒。相同原则也适用于环境比较：固定几何下的气相与 CPCM 水电子能差描述指定模型中的环境响应，不含完整的热力学与熵贡献\cite{cpcm}。

\subsection{激发态与响应张量的解释}
垂直激发保持核构型不变，完整线性响应 TDDFT 求取该几何上的电子激发信息\cite{tddft}。激发能、波长与振子强度需要按态一一对应，振子强度还需标明所采用的规范。单个最低激发能不能代表完整吸收光谱，离散跃迁也不包含实验谱线宽度与振动结构。

张量性质比标量能量增加了坐标与分量的对应要求。若正交矩阵 $\mathbf Q$ 将分子在实验室坐标系中主动旋转，则静态极化率的期望变换关系及各向同性量为
\begin{equation}
\boldsymbol\alpha'=\mathbf Q\boldsymbol\alpha\mathbf Q^{\mathsf T},
\qquad \alpha_{\mathrm{iso}}=\tfrac13\operatorname{Tr}(\boldsymbol\alpha).
\label{eq:tensor-rotation}
\end{equation}
在保持方法与数值条件一致时，旋转改变矩阵分量但应保持其迹。这为 H2 提供可检验的比较关系，当前尚无实际数值可实施该检查。H1 则关注核磁屏蔽张量，其迹的三分之一给出各向同性屏蔽；参考物换算属于另一环节，绝对屏蔽不能直接当作实验化学位移。

\section{Agent 架构}
\subsection{单一决策循环与任务代码生成}
Auto-ORCA 将自然语言需求转化为科学目标、计算条件与可执行计划。模型根据当前证据提出参数、Python 程序或 ORCA 输入；程序检查依赖、权限与资源后执行；新结果接受读取、检查与目标评价，并反馈至下一轮决策。图 \ref{fig:architecture} 给出总体结构。成功计算与失败信息均进入反馈，系统不预设优化、频率和单点的固定执行顺序。

任务特定算法由生成代码表达，通用工具负责输入校验、执行与产物管理。例如，程序可构建有限几何集合、逐一请求能量计算，再按统一单位比较结果。OPI 输入、原生 ORCA 输入和 Python 内部计算请求复用同一执行入口\cite{opi}；薄接口返回计算回执与原始产物，不封装针对单个问题的隐式求解算法。该设计使同一组工具能够处理不同任务，同时保留明确的执行边界。

\subsection{目标保持与证据管理}
系统使用 Request、Plan、Step、Tool、Run、Result 和 Artifact 表达需求、路线、操作、执行接口、运行记录、结果与原始产物。科学目标及最低证据要求独立于 Plan 保存，计划修改只改变实现路线。例如，在同一几何上比较气相与水环境能量，不能被无说明地改成两次独立优化；修复代码也不能通过删除目标获得形式上的完成。

这种表示的作用是把科学语义与执行过程明确连接。用户明确要求、默认设置、继承条件及自动选择分别记录；后续引用结构或数值时，绑定的是确定的产物及其来源，而不是一个可能随运行变化的“最新文件”。同一分子的不同目标可以使用不同环境或电子态，程序需按目标检查条件，而不能把所有设置无条件合并。

模型负责提出动作和修复建议，程序负责判定动作是否可执行以及输出是否满足规定检查。初始几何、输入、生成程序与各次原始输出独立保存，通过内容校验绑定来源。读取证据不隐式触发计算或转换，额外分析作为明确操作执行。对于尚未纳入标准检查的性质，可保存带来源、单位和限制说明的观察，模型或任务脚本不能自行授予科学资格。

\subsection{统一执行与开放性质观察}
在模型能够生成任务算法的同时，执行责任需要保持集中。工具定义同时提供参数约束、执行影响和输出声明；OPI、原生输入与内部计算请求遵循相同的管理方式。程序可以为一个科学问题组合多个计算，但每个计算仍保留自己的输入、几何、执行事实与产物。换一种输入表达方式，不改变资源限制或最低证据要求。

科学结果的获取也有不同层次。原始文件可读，说明证据能够访问；能从中提取字段，说明某个数据已取得；输出通过对应检查，才支持规定范围内的解释。对于现有检查尚未覆盖的性质，生成代码可以提取和组织带来源的观察，使新的分析问题获得可报告的结果，同时保留验证状态。该机制允许任务表达扩展，避免把脚本中的“通过”或一个正常退出码当作科学判断。

以张量分析为例，代码可以从原始输出读取矩阵并计算迹，但可靠解释还依赖原子索引、坐标方向和单位是否正确。以扫描为例，代码可以循环请求多个角度的计算，但目标角度标签本身不能证明终态几何满足约束。模型提出分析路线，实际执行与可检查证据共同限定这条路线的结论。

\subsection{反馈、资源与停止}
反馈保留原始目标、当前结果和有效诊断，并提供可查询的证据来源。错误信息用于定位输入、程序或求解失败；成功输出用于判断是否需要补充几何检查、采样或跨结果分析。执行状态不明时先核对已有事实，避免重复启动。

资源约束覆盖生成程序及其内部 ORCA 子计算。令预算维度 $k$ 的上限为 $B_k$、累计用量为 $U_k$、新动作预留为 $r_k$，执行前要求
\begin{equation}
U_k+r_k\leq B_k.
\end{equation}
内部计算、代码重试和模型纠错均计入累计用量，暂停或恢复不重置消耗。生成代码仅在受管理的任务环境中访问输入副本、必要运行库与任务产物目录。停止后保留已经完成的计算结果及尚未回答的问题。


修复需要继承原始目标与仍然有效的证据。输入格式修正、代码错误修复和科学方法调整具有不同含义，应在后续行动中分别说明。一次失败不抹去已经完成的其他计算；一次成功也不应使仍待核查的内容自动变为通过。当执行来源不清楚时，优先核对已有进程与产物，避免无根据地重复运行。

闭环的价值在于使反馈改变下一步操作。例如，频率结果可提示是否需要进一步处理几何，有限候选的能量差可支持是否继续采样的决定，张量提取结果可暴露单位或坐标约定的问题。这些是系统需要能够表达的后续路线；是否已经完成某条路线，仍需查看该问题的真实执行记录。预算与权限只决定哪些操作能够继续，不能改变原始科学条件或代替科学证据。

\section{计算方法与 Agent 能力测试}
\subsection{计算设置与科学任务}
计算使用 ORCA 6.1.1，并通过 OPI 2.0.0 及统一执行接口组织。所用本地资源为 4 核、计算进程树内存上限 1024 MiB、ORCA MaxCore 192 MiB/进程，环境计算并发为 1。MaxCore 为 ORCA 内部内存参数，与进程树总内存限制分别设置。

七个测试问题的实际方法见表 \ref{tab:task-overview}，已完成计算的体系均为中性单重态。r$^{2}$SCAN-3c 采用其内置 def2-mTZVPP 基组\cite{r2scan3c}；其他方法与基组按实际计算逐项报告，基组体系遵循 def2 定义\cite{def2}。垂直激发采用完整线性响应 TDDFT\cite{tddft}，水环境使用 CPCM 连续介质描述\cite{cpcm}。除明确说明的结构优化与约束优化外，各项结果均对应指定的固定几何。

结果检查可以从三个层次展开。首先，核对实际方法、几何和电荷多重度，使结果对应明确的计算问题。其次，依据 ORCA 原始输出确认是否正常结束，并检查目标数值是否实际保存。最后，核对解释是否超过证据范围，例如把有限集合中的最低单点能量误写成全局最低构象，或把固定几何的电子能量差误写成自由能。前两层使计算具有可追溯的对象与产出，后一层决定这些产出能够回答科学问题的程度。

因此，表 \ref{tab:agent-capability-design} 描述的是测试覆盖的能力维度，不能将其全部视为已经通过的能力。现有成功计算提供了多种任务表达、执行和数值交付的实例；更完整的能力评价还需要逐项确认依赖关系、几何对应及性质解释。七题成功率也不包含重复试验或对照系统的统计证据，不能据此估计未知任务的成功概率。后续可在保持目标与条件一致的前提下重复这些问题，逐项补齐未验证内容，进一步区分计算可完成性、结果可复核性与科学目标的完成程度。
\subsection{计算成功率与结果解释}
以 ORCA 原始输出的正常结束记录作为计算完成依据。对本文所列每个问题，只要已有相应 ORCA 计算正常完成并保存数值结果，即标记为\textbf{成功}；尚无实际数值结果则标记为\textbf{未完成}。因此，T3 的六个已完成计算点计为成功，其未计算端点与角度核查限制在结果中明确说明。
\begin{equation}
R_{\mathrm{calc}}=\frac{N_{\mathrm{success}}}{N_{\mathrm{questions}}}
=\frac{6}{7}\approx85.7\%.
\label{eq:success-rate}
\end{equation}
该比例以七个问题为分母，每题计数一次。科学结论根据实际收敛、几何、方法和性质证据分别解释：正常结束不单独证明全局最低构象、正确的扫描势垒或实验可比的响应量。

相对电子能量以指定候选集合内的参考值为零。能量换算使用 $1\,\Eh=2625.4996394799$ kJ mol$^{-1}$；电子能、振动频率、激发能与屏蔽张量保留原始输出或核查记录的精度。原始数据与来源记录用于复核和复用\cite{fair}。本报告呈现已有计算结果，不将所列成功率解释为任意新任务的成功概率，也不以缺少独立参考的能量差评价方法准确度。

\subsection{评价范围与复现条件}
七题的计算成功率描述 Agent 是否已经组织出相应的真实计算结果。若进一步评价数值准确度，还需要确认计算值与独立参考对应同一体系、几何、物理量和理论条件。对于具有可靠参考的任务，可分别报告有效对应的覆盖率与对应子集上的误差：
\begin{equation}
\mathrm{Coverage}=\frac{N_{\mathrm{matched}}}{N_{\mathrm{target}}},
\qquad
\mathrm{MAE}_{\mathrm{matched}}=
\frac{1}{N_{\mathrm{matched}}}\sum_{i\in\mathcal M}|y_i-y_i^{\mathrm{ref}}|.
\label{eq:coverage-accuracy}
\end{equation}
其中 $\mathcal M$ 只包含对应关系已确认的目标，$y_i$ 与 $y_i^{\mathrm{ref}}$ 使用相同单位。若 $N_{\mathrm{matched}}=0$，误差应记为不可评价。该表达说明后续准确度比较所需的条件，本文没有独立高精度参考，因而不报告实际 MAE，也不把不同方法或不同几何的能量差当作数值误差。

复现 Agent 测试还需要同时控制科学输入和决策环境。除了泛函、基组、电荷、多重度与原子坐标，应保存模型标识、推理设置、任务提示、工具定义、生成代码、资源上限以及停止条件。模型生成的程序和最终实际执行的输入应能够对应；有修复时，应保留原始失败与修改后的独立尝试。不同设置下出现相同的数值，并不足以证明中间决策过程完全相同。

成本评价也应区分模型调用与科学计算。模型请求数和 token 用量反映决策及上下文处理开销，ORCA 的计算次数、经过时间和 CPU 用量则反映数值求解成本。包含多个内部计算的任务程序需要累计核算子计算，不能只记一次外层工具调用。当前报告不将缺少统一核算条件的记录合并为成本排名；后续重复试验可以在固定目标与资源下，同时报告计算成功、结果可复核程度与成本，从而更完整地评价 Agent 能力。

\subsection{从计算可执行到持续探索}
七题的设计把 Agent 能力分解到可观察的操作要求上。T1 与 T2 检查结构来源、候选标识和计算条件的保持；T3 将要求推进到约束执行与实际几何的一致性；T4、T5 和 H1 进一步涉及多态输出、配对比较和矩阵组织。六项正常完成的计算说明通用工具与任务代码能够承载这些不同形式的求解。H2 缺少数值则明确指出，所设计的旋转一致性分析尚未获得结果支持。

这种结果具有实例层面的价值，但不能单独证明每个决策都已自主、正确地完成。证明闭环有效，需要观察新证据是否被后续步骤实际采用，以及补充操作是否减少了原始目标的不确定性。T3 的角度对应问题尤其说明，得到能量和得到可解释的扫描曲线之间仍有具体的验证环节。将缺口定位到几何、条件或性质检查，有助于安排下一项有意义的操作。

\subsection{有效性限制与后续评价}
当前结果规模有限，且不同问题具有不同的计算步骤和物理量。每题成功计数一次，适合报告所列问题是否已有实际计算产出；它不能直接衡量单次模型决策质量、全部步骤完成率或数值准确度。本文没有共同条件下的对照系统、重复试验分布与独立高精度参考，因此不据此作模型或架构的性能排名。

进一步验证可沿三条方向展开：在相同输入和资源条件下重复执行，检查结果及停止行为是否稳定；增加未见任务，检验生成代码是否能够迁移到新的操作组合；为实际物理量引入独立参考或确定性复核，区分执行错误与电子结构近似本身的误差。扫描任务应优先核对最终几何与端点，环境比较应保持共同条件，张量任务则应同时检查分量、单位和坐标变换。

对方法机制的比较也需要可控条件。目标与计划分离、修复信息继承和反馈内容组织可以作为后续研究的独立因素，但每项比较都应保持原始科学问题与最低要求不变。这样才能判断改进来自更可靠的任务组织，还是来自输入、预算或验收标准的变化。

\section{结论}
本文提出 Auto-ORCA，以单一 Agent 决策循环组合通用工具与生成代码，通过统一 ORCA 入口执行 DFT 任务，并分别保存原始目标、实际条件和数值证据。七个测试问题中，T1--T5 与 H1 已完成 ORCA 计算并取得结果，按本文定义的计算成功口径，成功率为 $6/7=85.7\%$；H2 尚无实际极化率数值。

主要结果包括乙醇的收敛优化结构与 21 个正频率、正己烷六个候选的单点能量、正丁烷六个约束优化点、丙酮五个单重态激发、两种基组下的气相与水环境电子能量差，以及 HCN 三核完整屏蔽张量。结构与性质的解释仍取决于各自证据：局部极小值不等于全局最优，正丁烷角度对应尚待核查，环境电子能量差不等于水合自由能。未来工作应围绕几何确认、采样完整性、响应张量验证和重复试验，进一步检验自主势能面探索的可靠性。
