\begin{abstract}
  分子势能面探索需要在结构准备、电子结构计算、收敛判断与后续采样之间反复作出决策，%
  固定脚本难以直接适应开放的科学需求。%
  本文提出 Auto-ORCA，将大语言模型的任务规划与代码生成能力连接至受管理的 ORCA 执行环境。%
  系统采用单一决策循环，将科学目标与可修订计划分离，通过通用工具校验并执行生成的 Python 和 ORCA 输入，%
  再依据真实输出组织后续行动。%
  为测试 Agent 的任务规划、代码生成、计算组织与结果处理能力，设置乙醇结构优化与振动频率、%
  正己烷候选构象能量、正丁烷二面角扫描、丙酮垂直激发、乙醇环境电子能量差、%
  HCN 核磁屏蔽及甲醛极化率七个问题。%
  按 ORCA 计算正常完成并产生数值结果的口径，六项标记为成功，计算成功率为 $6/7=85.7\%$。%
  乙醇优化收敛并获得 21 个正频率、0 个虚频；正己烷完成六个候选几何的单点能量比较；%
  丙酮获得五个单重态激发能；%
  两种基组下 CPCM 水环境相对气相的电子能量差分别为 $-18.276507$ 和 $-16.607972$ kJ mol$^{-1}$；%
  HCN 获得三核完整屏蔽张量。%
  正丁烷六个约束优化点计算成功，但实际二面角仍待独立核查；甲醛尚无极化率数值。%
  结果支持通用工具与生成代码组合执行多类 DFT 任务的可行性，%
  完整势能面结论仍需进一步的几何验证与采样证据。
\end{abstract}

\section{引言}
分子结构、构象稳定性与反应路径和势能面紧密相关。%
密度泛函理论（density functional theory, DFT）通过电子密度描述多电子体系，%
Kohn--Sham 框架为实际电子结构求解提供了基础\cite{hk,ks}。%
然而，单次求解只回答特定方法、几何与环境下的问题。%
势能面研究还需要组织结构优化、振动分析、候选比较及约束扫描，并根据中间结果决定下一步计算。%
方法和基组选择、电荷与自旋设定、结构准备、收敛诊断以及结果解释共同决定计算的有效性。

实际研究中的困难往往出现在步骤之间。%
一个已经完成的优化可能仍需频率检查，若干单点能量需要与各自几何一一对应，%
环境能量比较则要求保持共同条件。%
当任务不能直接套用已知协议时，研究者需要编写新的采样和分析程序。%
自主计算系统因而需要将自然语言需求、计算执行和科学证据连接为持续的决策过程，%
而不是只生成一个输入文件。

本文提出 Auto-ORCA，%
其完整名称为 \emph{LLM-Guided Autonomous Exploration of Potential Energy Surfaces Using DFT}。%
系统基于 ORCA 与 ORCA Python Interface（OPI）\cite{orca2020,orca6,opipaper}，%
通过单一 Agent 决策循环组合固定通用工具与现场生成代码。%
科学目标及最低证据要求独立保存，模型提出计划与任务程序，受管理工具负责实际执行并返回可追溯结果。

本文围绕三个问题展开：生成代码能否表达不同的分子计算任务，统一执行入口能否获得真实数值，%
以及这些数值能够支持何种科学结论。%
为考察 Agent 在这些环节上的能力，本文设置七个具有不同操作要求的测试问题。%
结构优化、构象比较与二面角扫描构成势能面相关测试；激发态、%
环境效应与响应张量则用于检验同一计算机制对其他性质的适应能力。%
研究重点是自主计算的组织与验证，不提出新的电子结构近似。%
本文的主要设计贡献是将开放的自然语言需求展开为可执行任务，将有限任务代码与统一 ORCA 入口结合，%
并使原始目标、计算证据和最终报告保持连续对应。%
这些机制共同服务于降低重复操作负担、扩展任务表达范围和提高结果可复核性的目标。

\section{相关工作与研究动机}
\subsection{从可追溯工作流到语义工具组合}
计算化学自动化首先需要解决的是执行的一致性。%
结构文件如何传递、输入采用何种条件、输出来自哪一次计算，以及异常终止后保留哪些证据，%
都会影响结果能否复核。%
ASE 以统一的原子结构与计算器接口连接不同模拟程序，AiiDA 将计算过程与数据来源联系起来，%
Atomate2 提供可组合的材料计算工作流，%
cclib 则支持不同量子化学软件输出的统一解析\cite{ase,aiida,atomate2,cclib}。%
这些工作共同建立了一个基础：自主决策应建立在明确的执行接口和可追溯数据之上，%
语言模型并不替代数值求解器与领域解析程序。

固定工作流适合计算条件明确、步骤依赖稳定的任务。%
例如，先优化结构，再计算频率，最后对所得结构计算单点能量，可以作为一种可重复使用的协议。%
但研究问题并不总能在执行前确定完整路线。%
优化得到的新构象可能要求重新比较候选；频率分析可能显示需要继续处理的几何问题；%
某个约束点的输出也可能使原定扫描范围失去充分性。%
此时，自动化需要理解步骤与科学问题之间的关系，并选择下一项有助于减少不确定性的操作。

语义工具组合把自然语言需求转化为既有工具的选择、参数与依赖，使用户能够以物理量和条件描述任务。%
它保留了专用工具的明确行为，但表达范围受工具目录限制：新的采样方法或跨结果分析若没有对应接口，%
仍需扩展工具实现。%
因此，从固定协议到语义组合的变化，主要是把路线选择交给模型；进一步引入任务代码，%
则允许模型表达有限循环、候选筛选和确定性分析。%
三种方法构成任务表达能力的不同层次，并不意味着后一种可以放弃前两种所要求的来源追踪和输入校验。

\subsection{语言模型 Agent 与闭环任务代码}
ReAct 将推理与行动交替组织，强调通过外部观察更新后续操作；Toolformer 研究模型学习使用工具的能力；%
Reflexion 则通过语言反馈支持任务修正\cite{react,toolformer,reflexion}。%
在化学领域，ChemCrow 将语言模型连接至专业工具，%
Coscientist 探索了模型协调化学研究操作的方式\cite{chemcrow,coscientist}。%
这些研究说明，模型可以承担需求解释和操作组织，但工具调用本身仍需要明确输入、%
可检查输出及领域知识支持。

对于电子结构计算，仅生成语法正确的 ORCA 输入仍不足以形成自主探索。%
输入描述的是某一次求解，而科学任务常由多个相互依赖的计算构成：待优化的几何来自哪里，%
下一步使用哪一份结构，多个能量是否具有相同条件，以及当前证据是否足以支持停止，%
都超出了单个输入文件的范围。%
闭环系统需要在计算之后重新评价这些问题，并将输出中的有效信息反馈给计划。%
将计算输出转化为下一次决策的依据，是构建这类闭环的关键。

任务代码为这种闭环提供了较灵活的表达方式。%
模型可以生成一个有限程序，将几何变换、计算请求和结果分析组合起来；程序执行后返回实际产物，%
模型再依据这些产物决定是否需要补充操作。%
其关键并非一次生成更长的脚本，而是保留每个内部计算与原始目标的对应关系。%
例如，构象比较程序需要同时保存候选几何和能量，使排序能够回到真实结构；扫描程序则需要使目标标签、%
优化后几何与实际二面角相互对应。%
代码是组织算法的载体，计算回执与原始输出才是执行已经发生的证据。

这种开放表达也引入新的要求。%
程序可能包含多个内部计算，单次工具调用的成功不能代表全部子问题已经回答；脚本能够提取一个数值，%
也不能自行证明该数值属于所需的物理量。%
因此，Auto-ORCA 将任务算法交由生成代码表达，同时通过共同执行入口管理计算条件、资源消耗和产物来源，%
使程序的灵活性与可检查的执行事实保持连接。

\subsection{闭环 DFT 自动化与 Auto-ORCA 的设计选择}
AutoDFT 面向 VASP 计算，将自然语言任务与晶体结构转化为步骤骨架，再依据已有结果生成各步参数。%
其七类 Agent 分担规划、执行、监控、修复、反思和性质提取；收敛结果仍可触发重算或计划调整，%
最终通过确定性后处理输出性质\cite{autodft}。%
文中开环基线先用一次 LLM 调用生成完整流程，后续仍含确定性的监控与恢复；%
闭环差异在于持续利用证据调整决策。

Auto-ORCA 将上述研究问题落在分子计算与势能面相关操作上，并采用单一 Agent 主循环组织决策。%
本文所说的意图识别、计划构建、代码生成、结果检查与报告编写，是同一决策过程在不同阶段承担的职责。%
工具负责执行边界，ORCA 负责电子结构求解，程序检查与原始证据共同约束最终解释。%
这种组织使任务的目标、条件和后续动作能够在同一上下文中保持连续，也便于将一个问题的输入结构、%
执行记录和最终结论对应起来。

从使用者角度看，系统的入口是研究问题。%
例如，用户提出“优化乙醇并判断所得结构的局部稳定性”，真正需要表达的是目标体系、计算条件和所需证据。%
Agent 将其展开为几何准备、优化求解、结构衔接、振动分析和结果解释，使计算步骤围绕同一问题组织。%
自然语言降低了任务表达对软件语法的依赖；保留方法、基组、电荷、多重度和环境等明确条件，%
则使这种便利能够与可复核的计算过程结合。

本项目的另一项设计特点是将通用工具与任务代码组合。%
对于有限候选比较，代码可以维护候选标识、几何文件和结果之间的映射；对于约束扫描，%
代码可以表达目标序列与逐点处理；对于多态或张量性质，代码可以完成统一格式整理。%
它们共享执行入口和产物管理方式，使新增任务能够首先通过现有能力的组合来表达。%
七个测试覆盖了上述不同操作形式，为这种组合方式提供了具体的计算实例。

\subsection{科学证据的对应关系与本文定位}
自主计算的评价应首先确认结果回答了哪个问题。%
Lee 与 Rondinelli 的自主多参考量子化学研究强调，%
计算收敛与电子态身份需要分别考察\cite{multirefagent}。%
如果没有确认所得态与目标态的对应关系，即使输出具有完整能量，也不足以直接进入目标性质的误差评价。%
这一研究提示，自主电子结构计算需要同时关注操作是否完成以及输出是否对应目标。%
本文将这种证据对应关系用于 DFT 任务的讨论；多参考求解、%
活性空间选择与电子态自动识别不属于本文已验证的能力。

在势能面相关任务中，对应关系表现为结构、条件与数值之间的联系。%
收敛优化结构需要结合振动信息解释局部稳定性；候选电子能量必须对应实际保存的几何；%
扫描能量需要与经过确认的构型坐标对应；跨环境比较需要保持指定的共同几何和电子结构条件。%
对于响应性质，还需要明确张量的坐标系、单位以及是否经过参考换算。%
数据的可发现性与可复用性有助于开展这些检查\cite{fair}，但材料齐备本身并不替代科学判断。

据此，本文关注三个相互连接的研究缺口：开放需求如何转化为有限且可执行的计算程序；计算成功或失败后，%
证据如何继续支持目标保持与计划调整；最终报告如何把已获得的数值和仍然缺失的验证清楚地对应到原问题。%
Auto-ORCA 以分子 DFT 任务为研究范围，通过单一决策循环、通用工具和生成代码研究这些问题。%
后文的七个测试用于检验 Agent 组织真实计算的能力；%
结构与性质结果同时用于分析该能力目前能够支持的科学结论。

进一步比较不同自主计算方案时，需要共同的任务定义、输入结构、最低证据要求和资源条件。%
计算覆盖、性质误差与运行成本回答不同的评价问题，应保留各自分母与适用范围。%
本文采用明确的问题级计算成功口径呈现已有结果，并在每个问题中说明数值的科学含义，%
为后续受控比较提供可复核的起点。

\section{科学任务的理论基础}
\subsection{势能面、结构优化与局部稳定性}
在 Born--Oppenheimer 描述下，给定核坐标 $\mathbf R$ 及电子结构条件 $\theta$，%
以气相基态 Kohn--Sham 能量为例，其基本组成可示意写为
\begin{equation}
  E_{\theta}(\mathbf R)=\min_{n}\!\left\{T_{\mathrm s}[n]
  +\int v_{\mathrm{ext}}(\mathbf r;\mathbf R)n(\mathbf r)\,\mathrm d\mathbf r
  +E_{\mathrm H}[n]+E_{\mathrm{xc}}[n]\right\}
  +E_{\mathrm{NN}}(\mathbf R).
\end{equation}
其中 $n$ 为满足电子数及指定自旋条件的密度，$T_{\mathrm s}$、%
$E_{\mathrm H}$ 和 $E_{\mathrm{xc}}$ 分别表示非相互作用动能、Hartree 能与交换相关能，%
$E_{\mathrm{NN}}$ 为核间排斥能\cite{hk,ks}。%
实际复合方法与溶剂模型还包含相应修正项。%
泛函、基组、电荷、多重度和环境共同定义实际求解条件。%
因此，能量必须与方法及几何一起报告；改变条件后，绝对能量不能直接作为同一势能面上的数值比较。

结构优化寻找势能面上的驻点。%
收敛判断依赖能量变化、梯度与位移等数值标准，驻点的局部性质还需通过振动分析判断。%
质量加权 Hessian 为
\begin{equation}
  H^{\mathrm{mw}}_{ij}=(m_i m_j)^{-1/2}
  \frac{\partial^2 E}{\partial R_i\partial R_j},
\end{equation}
其中 $i,j$ 遍历笛卡尔分量，质量按对应原子重复。%
振动子空间中的正本征值对应实振动频率。%
非线性 $N$ 原子分子具有 $3N-6$ 个振动自由度；乙醇含九个原子，因而对应 21 个振动模式。%
平动和转动模式需与真正振动分开解释，无虚频支持所得结构的局部稳定性，不能穷尽其他构象。

\subsection{候选比较、约束扫描与环境效应}
构象研究包含候选产生、几何处理与能量评价等不同环节。%
单点计算得到固定几何 $\mathbf R_i$ 上的 $E_{\theta}(\mathbf R_i)$；优化则允许核坐标变化，%
两者回答的问题不同。%
GFN2-xTB 与 CREST 等专门方法说明，构象采样与筛选本身具有独立的算法需求\cite{gfn2,crest}。%
本文的正己烷结果仅涉及已保存候选的 DFT 单点比较，不据此推断完整构象空间。

约束扫描在保持指定内部坐标条件的同时优化其他自由度。%
输入角度是计算指令，实际角度应由最终几何重算；对于周期坐标，%
可用包裹到 $(-\pi,\pi]$ 的角差比较目标与结果。%
能量曲线的横坐标必须来自可信的几何对应，才能进一步讨论极小值与势垒。%
相同原则也适用于环境比较：固定几何下的气相与 CPCM 水电子能差描述指定模型中的环境响应，%
不含完整的热力学与熵贡献\cite{cpcm}。

\subsection{激发态与响应张量的解释}
垂直激发保持核构型不变，完整线性响应 TDDFT 求取该几何上的电子激发信息\cite{tddft}。%
激发能、波长与振子强度需要按态一一对应，振子强度还需标明所采用的规范。%
单个最低激发能不能代表完整吸收光谱，离散跃迁也不包含实验谱线宽度与振动结构。

张量性质比标量能量增加了坐标与分量的对应要求。%
若正交矩阵 $\mathbf Q$ 将分子在实验室坐标系中主动旋转，则静态极化率的期望变换关系及各向同性量为
\begin{equation}
  \boldsymbol\alpha'=\mathbf Q\boldsymbol\alpha\mathbf Q^{\mathsf T},
  \qquad \alpha_{\mathrm{iso}}=\tfrac13\operatorname{Tr}(\boldsymbol\alpha).
  \label{eq:tensor-rotation}
\end{equation}
在保持方法与数值条件一致时，旋转改变矩阵分量但应保持其迹。%
这为 H2 提供可检验的比较关系，当前尚无实际数值可实施该检查。%
H1 则关注核磁屏蔽张量，其迹的三分之一给出各向同性屏蔽；参考物换算属于另一环节，%
绝对屏蔽不能直接当作实验化学位移。

\section{Agent 架构}
\subsection{单一决策循环与任务代码生成}
Auto-ORCA 将自然语言需求转化为科学目标、计算条件与可执行计划。%
模型根据当前证据提出参数、Python 程序或 ORCA 输入；程序检查依赖、权限与资源后执行；新结果接受读取、%
检查与目标评价，并反馈至下一轮决策。%
图 \ref{fig:architecture} 给出总体结构。%
成功计算与失败信息均进入反馈，系统不预设优化、频率和单点的固定执行顺序。

\begin{figure}[htbp]
  \centering
  \includegraphics[width=\linewidth]{auto-orca-architecture.png}
  \caption{Auto-ORCA 的单一决策循环。%
  原始目标与最低证据要求约束结果评价；模型通过通用工具组织受管理的 Python 与 ORCA 执行，%
  并依据返回证据调整计划。%
  }
  \label{fig:architecture}
\end{figure}

任务特定算法由生成代码表达，通用工具负责输入校验、执行与产物管理。%
例如，程序可构建有限几何集合、逐一请求能量计算，再按统一单位比较结果。%
OPI 输入、原生 ORCA 输入和 Python 内部计算请求复用同一执行入口\cite{opi}；%
薄接口返回计算回执与原始产物，不封装针对单个问题的隐式求解算法。%
该设计使同一组工具能够处理不同任务，同时保留明确的执行边界。

\subsection{目标保持与证据管理}
系统使用 Request、Plan、Step、Tool、Run、Result 和 Artifact 表达需求、路线、操作、执行接口、%
运行记录、结果与原始产物。%
科学目标及最低证据要求独立于 Plan 保存，计划修改只改变实现路线。%
例如，在同一几何上比较气相与水环境能量，不能被无说明地改成两次独立优化；%
修复代码也不能通过删除目标获得形式上的完成。

这种表示的作用是把科学语义与执行过程明确连接。%
用户明确要求、默认设置、继承条件及自动选择分别记录；后续引用结构或数值时，%
绑定的是确定的产物及其来源，而不是一个可能随运行变化的“最新文件”。%
同一分子的不同目标可以使用不同环境或电子态，程序需按目标检查条件，而不能把所有设置无条件合并。

模型负责提出动作和修复建议，程序负责判定动作是否可执行以及输出是否满足规定检查。%
初始几何、输入、生成程序与各次原始输出独立保存，通过内容校验绑定来源。%
读取证据不隐式触发计算或转换，额外分析作为明确操作执行。%
对于尚未纳入标准检查的性质，可保存带来源、单位和限制说明的观察，模型或任务脚本不能自行授予科学资格。

\subsection{统一执行与开放性质观察}
在模型能够生成任务算法的同时，执行责任需要保持集中。%
工具定义同时提供参数约束、执行影响和输出声明；OPI、原生输入与内部计算请求遵循相同的管理方式。%
程序可以为一个科学问题组合多个计算，但每个计算仍保留自己的输入、几何、执行事实与产物。%
换一种输入表达方式，不改变资源限制或最低证据要求。

科学结果的获取也有不同层次。%
原始文件可读，说明证据能够访问；能从中提取字段，说明某个数据已取得；输出通过对应检查，%
才支持规定范围内的解释。%
对于现有检查尚未覆盖的性质，生成代码可以提取和组织带来源的观察，使新的分析问题获得可报告的结果，%
同时保留验证状态。%
该机制允许任务表达扩展，避免把脚本中的“通过”或一个正常退出码当作科学判断。

以张量分析为例，代码可以从原始输出读取矩阵并计算迹，但可靠解释还依赖原子索引、%
坐标方向和单位是否正确。%
以扫描为例，代码可以循环请求多个角度的计算，但目标角度标签本身不能证明终态几何满足约束。%
模型提出分析路线，实际执行与可检查证据共同限定这条路线的结论。

\subsection{反馈、资源与停止}
反馈保留原始目标、当前结果和有效诊断，并提供可查询的证据来源。%
错误信息用于定位输入、程序或求解失败；成功输出用于判断是否需要补充几何检查、采样或跨结果分析。%
执行状态不明时先核对已有事实，避免重复启动。

资源约束覆盖生成程序及其内部 ORCA 子计算。%
令预算维度 $k$ 的上限为 $B_k$、累计用量为 $U_k$、新动作预留为 $r_k$，执行前要求
\begin{equation}
  U_k+r_k\leq B_k.
\end{equation}
内部计算、代码重试和模型纠错均计入累计用量，暂停或恢复不重置消耗。%
生成代码仅在受管理的任务环境中访问输入副本、必要运行库与任务产物目录。%
停止后保留已经完成的计算结果及尚未回答的问题。


修复需要继承原始目标与仍然有效的证据。%
输入格式修正、代码错误修复和科学方法调整具有不同含义，应在后续行动中分别说明。%
一次失败不抹去已经完成的其他计算；一次成功也不应使仍待核查的内容自动变为通过。%
当执行来源不清楚时，优先核对已有进程与产物，避免无根据地重复运行。

上述机制使反馈能够影响下一步操作，同时由原始科学条件、实际证据和剩余资源确定可继续的范围。

\subsection{开环与闭环的机制对照}
为更直观地说明结果反馈的作用，本文借鉴 AutoDFT 对开环规划与闭环执行的区分\cite{autodft}，%
在图 \ref{fig:open-closed-loop} 中比较两种组织方式。%
这里的开环表示：模型在开始时给出完整路线，执行期间主要依赖既定步骤和规则处理；它可以包含错误检测、%
规则重试和常规恢复。%
闭环则把新产生的科学证据重新纳入模型决策，使尚未执行的路线能够随问题认识的变化而调整。

  \includegraphics[width=\linewidth]{open-loop-vs-auto-orca.png}

  开环侧保留规则监控与恢复；闭环侧将成功结果及失败诊断返回同一 Agent，用于选择下一步、%
  修正程序或调整计划。%
  原始科学目标与资源上限共同约束后续行动。%
  该图为原创机制示意，不代表已开展开环基线性能实验。%
  }

在分子计算中，后续步骤往往需要前一步才能提供的信息。%
例如，频率分析应绑定实际得到的优化结构；构象比较需要先知道哪些候选具有可用能量；%
环境对比需要核对两个计算是否保持共同几何。%
将这些信息在执行后重新送入决策，可以使计划建立在已经获得的证据上。%
由此，Auto-ORCA 的闭环既支持处理异常，也支持利用成功结果推进科学问题。

Auto-ORCA 的设计优势体现在决策与执行责任的清晰连接。%

研究者因而可以在统一任务中表达计算、分析和解释需求，而无需为每一种组合另外建立完整专用流程。%
可调整的路线与稳定的问题定义相结合，为逐步扩展到更复杂的势能面探索提供了基础。

闭环也允许区分两类有价值的后续操作：一类是获得新的科学数据，例如补充一个候选能量；%
另一类是利用已有数据补齐解释所需的证据，例如检查最终坐标或核对原子索引。%
这种区分使继续工作能够针对真实缺口。%
若只需读取已保存的几何，就应先使用相应证据；只有现有数据无法回答问题且资源允许时，才规划新的计算。

\section{从自然语言到计算报告的端到端流程}
\label{sec:end-to-end-workflow}
Auto-ORCA 将用户的科学问题逐步转化为具有明确输入、计算条件和证据来源的可执行任务。%
其运行过程可概括为“自然语言输入—意图识别与条件确认—目标固定—计划组织—任务代码生成—受管 ORCA
执行—结果检查与反馈—最终交付”。%
这些环节由同一 Agent 主循环协调；后续动作取决于已经取得的事实，因此实际路线可以包含证据查询、%
计划修订和补充分析。%
下面按信息流说明各环节如何衔接。

\subsection{自然语言输入与科学意图识别}
任务入口同时接收自然语言描述与用户提供的结构、输出文件或已有结果引用。%
系统首先保存原始请求，并识别四类关键信息：研究对象是什么，需要获得什么物理量，计算应满足哪些条件，%
以及用户希望收到哪些材料。%
例如，“优化乙醇并计算振动频率”需要表达分子对象、结构优化、%
优化后结构上的频率计算及相应坐标和数值交付；%
“比较同一结构在两种环境中的能量”还需要保留共同几何和配对关系。

意图识别的输出是可检查的结构化候选，其中记录体系、目标、几何关系、条件、最低证据和仍待解决的信息。%
关键字段保留其原文依据，程序核对候选与用户消息的对应关系，随后保存规范化需求。%
这样，自然语言中的“同一几何”“前五个态”或“完整张量”等限定能够沿后续流程保留，%
避免只识别出宽泛的任务名称而遗漏交付细节。

\subsection{条件澄清与目标固定}
方法、基组、电荷、多重度、环境和几何来源共同确定实际计算问题。%
系统区分用户明确给出的条件、可追溯的继承条件、默认值和获得授权后的自动选择。%
缺失信息以待确认项保留；对会改变计算对象或结果含义的缺口，Agent 可以提出针对性问题。%
用户已委托的方法或基组选择则可形成带理由的选择记录，并在计算启动前检查其与其余条件的相容性。

条件确认后，目标及最低证据要求独立于执行计划保存。%
一个请求可以包含多个目标，各目标可分别约束体系、环境、电子态和几何关系。%
例如，气相与溶液中的能量比较需要保留两个环境目标及其共同几何，%
不能被压缩成一个没有环境区分的“能量”字段。%
目标固定使路线保持灵活：计划可以增加解析步骤或修复输入，但仍需回答原来的科学问题。

\subsection{依据依赖关系组织计算计划}
Agent 随后将目标转化为若干相互依赖的操作，包括读取或准备结构、生成输入、执行计算、%
提取性质及整理结果。%
每一步明确使用哪个体系、消费哪些已登记文件、调用哪个工具，以及预计提供什么输出。%
程序检查计划与目标的关联、文件依赖、工具权限和可用预算；%
只有前置数据已经具备且满足该步骤所需检查的操作才进入执行选择。

计划的价值在于把科学上的先后关系落实为数据关系。%
优化后的频率计算必须取得相应的终态结构；候选能量排序必须保留每个能量与候选标识的对应；%
旋转一致性分析则依赖两个取向的计算结果和旋转定义。%
需要修改路线时，系统生成新的计划版本，已经执行的输入与尝试保持原记录。%
这使探索过程既能利用新信息调整，又能解释每个结果由哪条路线产生。

\subsection{生成任务代码并通过统一工具边界}
对于固定接口难以直接表达的任务，Agent 可编写任务 Python 和 ORCA 原生输入，完成循环计算、字段提取、%
矩阵整理或确定性派生量分析。%
代码先作为有来源的文件保存，再由执行步骤引用。%
执行前检查代码及输入的身份、文件依赖和任务声明，生成程序在受管理环境中运行；%
内部 ORCA 请求仍由统一入口处理。

这种组织方式使新任务主要体现为操作组合和任务程序的变化。%
例如，构象比较需要管理一组几何与能量，激发态分析需要整理逐态输出，%
屏蔽分析需要保持原子索引和矩阵分量。%
三者可使用共同的写入、执行、查询和归档机制。%
程序提供通用计算能力，工具边界则使实际输入、资源消耗和原始产物始终可追溯。

\subsection{执行、监测与原始产物归档}
启动前，系统核对实际输入、几何、条件、许可和资源余量，并为该次操作保存独立记录。%
任务代码及其内部 ORCA 计算共享受控的执行环境与累计资源约束。%
启动事实由受信任的执行回执确认；若执行状态尚不明确，首先核对已有进程与回执，%
避免把未知状态当作未启动并重复计算。

执行结束后，系统归档输入、标准输出、错误日志、结构文件和性质文件，并建立结果与原始产物的对应关系。%
正常完成与失败均保留记录。%
对于包含内部 ORCA 调用的 Python 任务，外层脚本状态和内部计算状态分别记录，因此可以发现“脚本已返回，%
但内部计算因输入错误退出”的情形。%
该层次化记录为后续定位提供具体对象，也使成功数值与失败原因能够共同进入反馈。

\subsection{结果检查与基于证据的继续决策}
新结果返回后，主循环先重新评价目标，再决定下一步操作。%
检查内容包括实际条件、文件完整性、输出可读性以及适用的科学检查。%
已有检查覆盖的输出按对应规则判断；新性质可由任务代码提取为带来源、单位和验证说明的观察。%
结果读取成功、计算完成、观察可报告与科学要求获得验证分别记录，使最终结论能够对应真实证据。

成功反馈可以触发下一项必要分析。%
例如，优化完成后需要取得终态结构及频率证据；候选计算完成后需要整理对应关系并统一能量单位。%
失败反馈则携带具体字段、程序错误或 ORCA 日志位置，供 Agent 提出有针对性的修复。%
修复使用新的输入或后续步骤，继承原目标及仍然有效的来源；原始失败保持可查。

系统还检查是否存在仍可执行的当前目标工作。%
当批准的后续步骤、可恢复失败或已归档原件的分析路线仍然可用时，反馈指出对应继续入口，%
终端交付检查据此避免过早停止。%
已有文件足以支持分析时，继续路线可以只增加解析操作。%

\subsection{计算成功率与结果解释}
以 ORCA 原始输出的正常结束记录作为计算完成依据。%
对本文所列每个问题，只要已有相应 ORCA 计算正常完成并保存数值结果，即标记为\textbf{成功}；%
尚无实际数值结果则标记为\textbf{未完成}。%
因此，T3 的六个已完成计算点计为成功，其未计算端点与角度核查限制在结果中明确说明。
\begin{equation}
  R_{\mathrm{calc}}=\frac{N_{\mathrm{success}}}{N_{\mathrm{questions}}}
  =\frac{6}{7}\approx85.7\%.
  \label{eq:success-rate}
\end{equation}
该比例以七个问题为分母，每题计数一次。%
科学结论根据实际收敛、几何、方法和性质证据分别解释：正常结束不单独证明全局最低构象、%
正确的扫描势垒或实验可比的响应量。

相对电子能量以指定候选集合内的参考值为零。%
能量换算使用 $1\,\Eh=2625.4996394799$ kJ mol$^{-1}$；电子能、振动频率、%
激发能与屏蔽张量保留原始输出或核查记录的精度。%
原始数据与来源记录用于复核和复用\cite{fair}。%
本报告呈现已有计算结果，不将所列成功率解释为任意新任务的成功概率，%
也不以缺少独立参考的能量差评价方法准确度。

\subsection{评价范围与复现条件}
七题的计算成功率描述 Agent 是否已经组织出相应的真实计算结果。%
若进一步评价数值准确度，还需要确认计算值与独立参考对应同一体系、几何、物理量和理论条件。%
对于具有可靠参考的任务，可分别报告有效对应的覆盖率与对应子集上的误差：
\begin{equation}
  \mathrm{Coverage}=\frac{N_{\mathrm{matched}}}{N_{\mathrm{target}}},
  \qquad
  \mathrm{MAE}_{\mathrm{matched}}=
  \frac{1}{N_{\mathrm{matched}}}\sum_{i\in\mathcal M}|y_i-y_i^{\mathrm{ref}}|.
  \label{eq:coverage-accuracy}
\end{equation}
其中 $\mathcal M$ 只包含对应关系已确认的目标，$y_i$ 与 $y_i^{\mathrm{ref}}$ 使用相同单位。%
若 $N_{\mathrm{matched}}=0$，误差应记为不可评价。%
该表达说明后续准确度比较所需的条件，本文没有独立高精度参考，因而不报告实际 MAE，%
也不把不同方法或不同几何的能量差当作数值误差。

复现 Agent 测试还需要同时控制科学输入和决策环境。%
除了泛函、基组、电荷、多重度与原子坐标，应保存模型标识、推理设置、任务提示、工具定义、生成代码、%
资源上限以及停止条件。%
模型生成的程序和最终实际执行的输入应能够对应；有修复时，应保留原始失败与修改后的独立尝试。%
不同设置下出现相同的数值，并不足以证明中间决策过程完全相同。

成本评价也应区分模型调用与科学计算。%
模型请求数和 token 用量反映决策及上下文处理开销，ORCA 的计算次数、%
经过时间和 CPU 用量则反映数值求解成本。%
包含多个内部计算的任务程序需要累计核算子计算，不能只记一次外层工具调用。%
当前报告不将缺少统一核算条件的记录合并为成本排名；后续重复试验可以在固定目标与资源下，%
同时报告计算成功、结果可复核程度与成本，从而更完整地评价 Agent 能力。

\section{讨论}
\subsection{跨任务执行与科学解释}
六项成功结果覆盖结构优化、谐振频率、单点能量、约束优化、垂直激发、环境能量比较及核磁屏蔽，%
说明生成程序可以围绕共同 ORCA 入口组织不同类型的计算。%
正己烷候选能量与丙酮激发响应的具体数值见前述结果表，分别体现集合计算与多态结果整理的能力。

与势能面直接相关的结果具有不同证据范围：T1 的收敛优化和无虚频支持局部极小值；%
T2 给出有限候选几何上的单点排序；T3 保存了六个收敛约束优化点，但缺少经过独立确认的角度对应。%
因此，现有结果支持势能面相关操作的执行能力，%
尚不能据此宣称完成全局势能面搜索或获得可信的完整扭转势垒。

性质计算同样需要明确物理量含义。%
T4 对应固定准备几何上的垂直激发，T5 给出固定几何下的电子能量差，H1 给出绝对核磁屏蔽。%
H2 尚无张量数值，不能开展旋转一致性验证。%
后续验证应优先补齐这些具体缺口，并采用相同条件下的重复计算及独立参考评价可重复性和准确度。

\subsection{以目标保持和证据衔接支撑持续探索}
Auto-ORCA 的研究价值还体现在把用户问题贯穿到最终交付。%
自然语言请求通常同时包含目标、条件和期望解释，而一次 ORCA 求解只能产生其中一部分信息。%
因此，每个结果进入下一轮决策时，都需要回到当前问题：它来自哪个结构，采用何种条件，已经回答了什么，%
接下来还需要哪类证据。%
这种逐步衔接使长任务能够拆分为可执行、可检查的小步骤，同时保留整体研究方向。

以本文的 T1 为例，优化输出提供电子能量与收敛几何，频率分析进一步支持局部稳定性的解释。%
两项证据的结合使最终报告能够给出“该方法下的局部极小值”这一明确结论。%
T2 中的候选标识和单点能量则共同构成有限集合内的比较依据；%
T5 通过同一初始几何及配对计算条件支持环境电子能量差的解释。%
这些实例表明，任务组织的质量可以体现在结果之间是否建立了清楚且科学上有效的联系。

反馈同样可以来自成功计算。%
一个正常结束的输出可能提供新的构型信息，也可能暴露需要补充核查的条件。%
对这些信息进行整理，可为下一步结构确认、采样扩展或性质分析提供具体依据。%
T3 保存的六个能量点和角度对应问题，就将后续工作定位到了可检查的几何关系；H2 缺少实际张量，%
则明确了继续开展旋转一致性分析所需的计算前提。%
把后续动作与这些具体证据联系起来，有助于使探索保持可解释性。

在报告层面，结构化结果与自然语言解释承担互补作用。%
表格和矩阵保留数值、单位及对象标识，文字说明则交代计算方法、物理含义和适用范围。%
用户既能够快速理解主要发现，也能够沿结果返回原始产物进行复核。%
对自主科研系统而言，这种交付方式使自动计算的价值延伸至研究沟通与后续复用：%
研究者能够从已有结果出发提出新的问题，而无需重新梳理全部输入与输出。

上述优势主要体现在任务组织、接口一致性和证据表达上。%
本文七题提供了其适用于多种分子计算操作的实例，按既定口径有六题取得实际 ORCA 结果。%
后续可在共同任务与资源条件下，进一步测量从自然语言输入到结果交付所需的人工操作、修复次数和计算成本，%
从而把当前展示的组织能力推进为可比较的效率与可靠性评价。

\subsection{有效性限制与后续评价}
当前结果规模有限，且不同问题具有不同的计算步骤和物理量。%
每题成功计数一次，适合报告所列问题是否已有实际计算产出；它不能直接衡量单次模型决策质量、%
全部步骤完成率或数值准确度。%
本文没有共同条件下的对照系统、重复试验分布与独立高精度参考，因此不据此作模型或架构的性能排名。

进一步验证可沿三条方向展开：在相同输入和资源条件下重复执行，检查结果及停止行为是否稳定；%
增加未见任务，检验生成代码是否能够迁移到新的操作组合；为实际物理量引入独立参考或确定性复核，%
区分执行错误与电子结构近似本身的误差。%
扫描任务应优先核对最终几何与端点，环境比较应保持共同条件，张量任务则应同时检查分量、单位和坐标变换。

对方法机制的比较也需要可控条件。%
目标与计划分离、修复信息继承和反馈内容组织可以作为后续研究的独立因素，%
但每项比较都应保持原始科学问题与最低要求不变。%
这样才能判断改进来自更可靠的任务组织，还是来自输入、预算或验收标准的变化。

\section{结论}
本文提出 Auto-ORCA，以单一 Agent 决策循环组合通用工具与生成代码，通过统一 ORCA 入口执行 DFT 任务，%
并分别保存原始目标、实际条件和数值证据。%
七个测试问题中，T1--T5 与 H1 已完成 ORCA 计算并取得结果，按本文定义的计算成功口径，%
成功率为 $6/7=85.7\%$；H2 尚无实际极化率数值。

从工作流程看，Auto-ORCA 将自然语言输入、意图识别、条件确认、依赖规划、任务代码、%
受管执行和结果解释连接为连续过程。%
成功结果用于推进目标，失败诊断用于形成针对性修复，最终报告则将结论关联到实际方法与原始产物。%
这种组织使研究者能够围绕科学问题展开多步计算，也为继续分析和复用既有结果提供了清楚的起点。

主要结果包括乙醇的收敛优化结构与 21 个正频率、正己烷六个候选的单点能量、正丁烷六个约束优化点、%
丙酮五个单重态激发、两种基组下的气相与水环境电子能量差，以及 HCN 三核完整屏蔽张量。%
结构与性质的解释仍取决于各自证据：局部极小值不等于全局最优，正丁烷角度对应尚待核查，%
环境电子能量差不等于水合自由能。%
未来工作应围绕几何确认、采样完整性、响应张量验证和重复试验，进一步检验自主势能面探索的可靠性。
