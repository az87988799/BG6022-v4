\subsection{v2：真实计算链与可重解析的科学证据}
\label{sec:v2}

频率证据分别包含 3、21 个正振动模式，历史科学策略据此给出 \code{supported\_within\_policy} 的局部极小值支持。定义 $\Delta E=E_{\mathrm{SP}}-E_{\mathrm{Opt,final}}$，两者的有符号能量差分别为 $-2.0\times10^{-11}\,\Eh$ 和 $2.381\times10^{-9}\,\Eh$；这只是内部重复评价差，不能表述为电子结构方法的外部准确度。两条可移植归档各 33 个文件的大小与 hash 在本次只读核查中全部匹配，原始输出和 Hessian 可以追溯到冻结账本。

版本演进体现了评价对象的改变：v2 验证批准后的固定计算链，v3 在有限已定义任务上扩大组合与对话，v4 将更多任务算法交给现场代码，同时要求原目标、产物和检查贯通。v3 的 18/18 与 v4 的 0/7 没有共同任务分母，也缺少统一版本、模型和提示的受控对照；不能直接推导性能下降或上升。

历史成果可以支持已验证组件与方法设计的经验基础，但旧系统的科学检查、对象生命周期和运行资格不能自动迁入 v4。报告补充的是证据与分析，不恢复 v2 的数据库、Kernel/Reducer 或旧对话协议，也不改变 v4 的单协调者契约。后续若要证明版本收益，应冻结同一组用户目标、最低证据、输入与资源，分别测量完整交付、数值误差和成本。
