# 报告量化图的来源与复算

数据来自报告根目录的 `experiment-data.json`。每条任务、批次、候选能量与成本记录均附仓库相对来源路径和行号；科学原始文件及 hash 进一步保存在这些验收报告的证据索引内。本次只读取已提交的历史证据，没有新增模型请求、ORCA 或独立参考计算。证据 Git 截点为 `def9e31d3cec99cd915d3d57e2a1079d04d2e1f2`（2026-10-21，Asia/Hong_Kong），不将当前未提交的 v78/0057 修复当作真实复验。

生成命令：`python make_figures.py`，需要 Python 3.11+ 与 Matplotlib。本次使用 bundled CPython 3.12、Matplotlib 3.10.7、NumPy 2.5.4；绘图库临时装入本目录的 `.runtime/`，没有改变产品依赖或外部 Python 环境。该本地临时依赖由 `.gitignore` 排除，不属于报告交付；可选绘图依赖版本见 `../requirements-figures.txt`。脚本不使用产品模型、ORCA 或科学 SDK；先核对逐题及跨批总数，再使用 Decimal 从公开的 Hartree 能量重算相对能量，最后输出三幅 PDF 和同名 PNG。绘图风格为白底、navy/teal/amber、嵌入 TrueType 的矢量 PDF；最小文字 9 pt。

- `latest-tasks.pdf/.png`：最新重冻结 3 批次（候选 `89d55708`、提示 v77）七题的模型 tokens 与 ORCA 启动/正常结束。逐题汇总为 53 次调用、1,048,678 tokens、8 次 ORCA 启动及 7 次正常结束。完整目标为 0/7；正常终止不是科学资格或目标完成。H1/H2 在此时已经暴露，属于回归题。
- `bounded-conformers.pdf/.png`：步骤 5 live006 中 12 份实际保存候选里的 4 项 B3LYP/6-31G 单点相对能量。差值以这 4 项最低能为零，不涉及另外 8 项，不是 ORCA 优化、频率、自由能或全局最低结论。最终交付包含明确披露的开发者元数据协助，不能当作无人干预正式跨任务成功。
- `evaluation-history.pdf/.png`：首轮及三次重冻结批次的模型 tokens 和实际 ORCA 启动。各批次完整目标均为 0/7；候选版本不同、题目反复暴露，不是同一版本的重复实验，不支持成功率改善趋势。累计为 294 模型调用、5,512,391 tokens、13 次 ORCA 启动；早期开发正例和开发者探针不并入该总数。

相对能量换算常数为 `2625.4996394799 kJ mol^-1 Eh^-1`，来自步骤 5 原记录。JSON 以字符串保留输入十进制能量；脚本从这些公开舍入值重算的差值与原报告六位小数相符（误差不超过 `5.1e-7 kJ/mol`）。PDF 柱上标签为显示舍入，不增加计算精度或独立科学验证。

JSON 中费用为冻结价表估算上界，CPU/计算经过时间为不完整采样的观测下界；未查询供应商实际账单，图中不呈现费用比较。所有图只描述相应历史范围，未运行的参考、完整控制矩阵、正式三次重复或真实集群均不记为已验证。
