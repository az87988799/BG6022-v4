# ORCA DFT Agent

本仓库用于建设通用 ORCA 计算 Agent，目标支持自然语言驱动计算、已有结果分析，以及基于证据的有界反馈决策。

## 当前状态

已建立项目文档基准，尚未开始实施阶段 A；未实现或验证任何科学计算能力。后续按照用户逐次提供的详细实现方案开发，不将总蓝图视为一次性实施全部阶段的授权。

## 开发依据

- [唯一现行总蓝图](docs/ORCA-Agent-Project-Blueprint.md)：版本 2.0，日期 2026-10-06，完整保留用户提供的方案。
- [开发约定](AGENTS.md)：强制原则、任务边界、验证与提交要求。

蓝图中的目录、接口和验收场景是建设约定，不代表已有实现。优先打通真实本地计算与可靠证据，再逐步加入目标约束下的反馈决策和其他能力。

## 任务交付

每次按照详细方案明确范围与退出条件，完成实现和必要验证后提交 Git，并推送至 [az87988799/BG6022-v4](https://github.com/az87988799/BG6022-v4.git)。交付时说明提交、验证结果、真实证据与限制，等待用户验收；用户接受后才记录验收通过。
